## 关键技术发现

### 1. `CreateWindowExW` 同步 dispatch WM_CREATE

```
[LayoutDialog ENTRY] clientW=360 clientH=460 s_hwnd=N s_hList=Y
```

- `CreateWindowExW` 在返回前就 dispatch `WM_CREATE`, WndProc → OnCreate 同步执行
- 此时 `s_hwnd = CreateWindowExW(...)` 赋值还没运行 (Show() 的赋值)
- OnCreate 末尾任何依赖 `s_hwnd` 的 helper (例如 LayoutDialog) 都早返回
- **修法**: OnCreate 入口 `s_hwnd = hwnd;` (用 WndProc 参数, 不依赖 Show() 赋值)
- **影响范围**: 不止 LayoutDialog, 任何 OnCreate 末尾的 helper (e.g. SetWindowPos on dialog itself, animation setup) 都要考虑这个时序

### 2. ListView column width 时序

- `ListView_InsertColumn` 不设 cx → default 10px (ListView 自动)
- PopulateList 后 scrollbar 显示 → header client = ListView client - scrollbar
- 正确 column width = header client - 4 (slack)
- v0.19.0.44 OnCreate 设 `col.cx = raw clientW - 2*gap - 4`, 但 OnCreate 末尾 LayoutDialog 早返回 → cx 没修正
- **修法**: OnCreate InsertColumn 删 cx (只 LVCF_TEXT + LVCF_SUBITEM), LayoutDialog 统一算

### 3. UI margin 统一

- `kBtnMarginX = 12` 单边过宽, input + AddTop + 底部按钮 各浪费 12px
- 改 `kGap = 8` 节省 8px 单边 (= 8px @ DPI=1), 让 input 宽 8px
- 整 UI 边距统一 `gap` (input/list/AddTop/底部按钮), 视觉对称

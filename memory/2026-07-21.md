### 异常 1: cmd.exe /c 在 git bash 下被吞 `/c` flag

git bash 的 MSYS 路径转换把 `cmd.exe /c "..."` 的 /c 转成路径。
试了 `cmd //c`、`cmd '/c'`、PowerShell 包装,前 3 次都进 interactive shell。
最后 `powershell -Command "& cmd.exe /c '.\\_run_build_2026_07_21.bat'"`
才 work。**下次**: 直接用 PowerShell 包 cmd + batch file (`.bat` 前缀必带 `.\\`)。

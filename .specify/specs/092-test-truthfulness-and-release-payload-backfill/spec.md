- **状态**：已实现（代码 + 文档已落地，待完整套件与真机复验）
- **日期**：2026-10-31
- **来源**：spec 091 交付后的「系统性问题清单」（交接文档 §6.2 七项）+ 本轮新查出的一项
- **关联**：spec 036 / spec 038 / spec 045（快捷面板两代设计漂移）、

## 1. 用户可见的问题

### 1.1 「测试全绿」曾经是假的（US092-A，本轮主线）

有两处检查**从来没有真正跑过**，但每次跑完整套件都显示「通过」：

| 检查 | 表面状态 | 实际状态 |
|---|---|---|
| 快捷面板结构检查 | 输出「通过」 | 整段被跳过，实际一条断言都没执行 |
| 候选屏蔽检查 | 输出「通过」 | 无论断言成败，一律打印「通过」 |

后果：这两处检查**既不能发现问题，也不能证明没问题**。
用户接收「测试全绿」这个结论时，会以为它背后真的有检查在跑。

### 1.2 发布目录缺两个历史版本的安装包（US092-B）

`release/` 目录里缺 1.1.1 与 1.1.2 两个版本的安装包。
这两个版本**曾经发布过**，用户从仓库下载时找不到对应文件。

### 1.3 变更记录挂着早已发布的旧条目（US092-C）

变更记录里「未发布」段下面，还挂着两个版本之前就已经发布过的内容。
读的人会误以为那些东西还没发出去。

### 1.4 决策记录没有编号索引（US092-D）

决策记录目录有 19 篇决策文档，但目录页里没有编号索引
⇒ 想知道「第 17 号决策说了什么」只能靠翻文件名。

## 2. 期望的用户可见行为

| # | 场景 | 期望结果 | 与之前相比 |
|---|---|---|---|
| A1 | 跑完整套件 | 每一条被检查的断言都真的执行过，并按实测结果报「通过 / 不通过」 | 有跳过、有假通过 → 全部实跑 |
| A2 | 快捷面板结构检查 | 按**当前**面板的实际形态判定（类名、自绘、复用、命中、点击路由） | 期待早已不成立的布局 → 按现行契约重写 |
| A3 | 候选屏蔽检查 | 断言失败时必须报「不通过」 | 永远报「通过」 → 按实测判定 |
| A4 | 从发布目录取 1.1.1 / 1.1.2 安装包 | 文件存在，且与当初发布的原件逐字节一致 | 缺失 → 从原件回填 |
| A5 | 读变更记录 | 「未发布」段只留本轮内容；已发布内容归到对应版本段 | 旧内容错位 → 各归其位 |
| A6 | 查决策记录 | 目录页有一张编号索引，能直接查到 19 篇的编号 / 标题 / 状态 | 无索引 → 补索引 |

## 3. 验收标准

| # | 验收动作 | 通过判据 |
|---|---|---|
| AC-1 | 跑完整套件 | 退出码 0，且**没有任何一条检查被跳过** |
| AC-2 | 查两个快捷面板检查的输出 | 两边都出现按实测计数的「通过 / 不通过」，且没有「跳过」字样 |
| AC-3 | 故意把候选屏蔽检查里的一条断言改坏 | 该检查必须报「不通过」，套件退出码非 0 |
| AC-4 | 比对 `release/` 里的 1.1.1 / 1.1.2 安装包 | 字节数与校验值与原件一致 |
| AC-5 | 查变更记录 | 「未发布」段只含本轮条目；1.1.0 / 1.1.1 两段就位 |
| AC-6 | 查决策记录目录页 | 索引表列出 19 篇决策；`0002`–`0006` 被注明为未使用 |

## 4. 边界（明确不做）

1. **不改**任何产品功能代码 —— 本轮只动测试、文档与发布载荷。
2. **不改**快捷面板的**实际行为**：本轮只是把检查改成「认当前的行为」，
   不是把面板改回老样子。
3. **不删**快捷面板接口上的历史参数 —— 那属于接口变更，需要另开决策记录。
4. **不动** `output/install.nsi`、`output/data/user-custom/**`、`librime/`。
5. **不碰**真机上的旧版嵌套目录（`weasel\fluxing\weasel\`），只向用户报告。
6. **不自行开工**下一轮的三个候选方向（统一设置面板 / 对称位标志协议表 / 命令行解析加固）。

---

## 5. 术语

- **实跑**：检查真的执行了每一条断言，并按实测结果报通过或不通过。
- **探针无判别性**：检查无论结果如何都报「通过」，等于没有检查。
- **跳过**：检查整段不执行（早期 return / 跳过分支），输出看着像通过。
- **载荷仓**：`release/` 目录，存放各版本安装包。
- **现行契约**：面板**当前**生产代码实际表现出来的行为，不是历史设计稿上的行为。

## Phase 2 — 锁定降级文件名（US2）

### T2.1 [US2] 安装脚本：版本化落地文件名加每次安装唯一序号
- **优先级**: P1
- **输入文件**: `output/install.nsi`
- **产出**: 32 位与 64 位两条对称分支的落地文件名尾部带序号；序号从 0 起探测最低空闲值；上界 64
- **要点**: 探测复用删除动作（删除对被映射文件失败、对不存在文件成功）；探测循环后清错误标志；触界时落回既有降级路径；文件必须保持 UTF-8 + BOM + CRLF
- **Done**: 安装脚本编译门禁零错误；最小探针证明写入目标名会展开运行时变量（产出目录里只有展开后的名字，没有字面量形式）；`Select-String` 能查到序号变量的声明与两处分支的探测循环

### T2.2 [US2] 门禁新增阶段：锁定状态下再装一遍并断言不产生待替换标记
- **优先级**: P1
- **输入文件**: `scripts/sandbox-gate/in-sandbox-claims.ps1`
- **产出**: 新增阶段，位于卸载清理之前；独占锁住普通名文件与当前最大序号副本两个文件；断言覆盖：安装成功、找到新序号副本、副本内容与构建产物一致、系统注册指向新副本、**不产生待替换标记**
- **要点**: 「不产生待替换标记」是判别性主断言（旧实现下必然失败）；「找到新序号副本」在旧实现下会跳过而不是失败，不能当判别点；锁句柄必须在 `finally` 里关闭
- **Done**: 门禁脚本语法解析零错误；一轮真跑后机器可读报告里新增断言全部为 PASS，且失败项集合没有超出已知恒失败项

### T2.3 [US2] 门禁修正：选包规则与断言编号
- **优先级**: P1
- **输入文件**: `scripts/sandbox-gate/run-verify.ps1`、`scripts/sandbox-gate/in-sandbox-claims.ps1`
- **产出**: 选包正则第四段改为可选并有兜底；新增断言使用完全空闲的新编号前缀；工具版本号抬升
- **要点**: 正则站点共四处，两处脚本各两处，全部同步；缺省分支时必须判可选组是否命中，否则版本解析会抛异常；既有阶段里靠包名反推构建号的那处必须改成从文件系统反查
- **Done**: 选包正则三样本自测通过（三段式包名选中 / 四段式基线包仍作升级基线 / 垃圾名排除）；新增编号与既有编号零重叠；工具版本号已抬升；一轮真跑后待验包确实被选中（不再静默失败退出）

### T2.4 [US2] 事故记录 L164 + L165
- **优先级**: P2
- **输入文件**: `.specify/memory/lessons-learned.md`
- **产出**: L164（锁定降级文件名缺每次安装唯一分量 ⇒ 第二次同版本安装静默退回待替换）+ L165（门禁自身腐化不会报错：选包契约漂移让它静默选不出包、断言编号撞号让它静默产出损坏报告）
- **要点**: 两条同属「坏了但不报错」，合并成一条更连贯；文件必须保持 BOM + 纯 CRLF
- **Done**: 补丁脚本输出 `OK selftest=pass`；`Select-String '^## L16[45]'` 各命中一次；安装脚本里的引用能解析到真实条目

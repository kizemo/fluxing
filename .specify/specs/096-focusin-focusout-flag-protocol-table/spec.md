# spec 096 — 焦点进出的对称位标志协议表

## 背景

前台与输入法服务之间的「焦点进入 / 焦点离开」通知，各自带了一组位标志。
两侧的标志是**分别长出来**的：第 0 枚在两侧各有一个，值相同、语义对称，
但写在两个彼此没有约束的枚举里，谁也不引用谁。

由此暴露三个缺口：

1. **焦点进入侧没有共享判定口径**。焦点离开侧有一份共享的判定函数，
   焦点进入侧的判定则散落在服务端的调用点里，自己写位与运算。两侧不对称，
   将来加语义时极容易只改一侧。

2. **焦点进入侧无法正向表达「窗口获得焦点」**。普通窗口焦点事件过去发的是
   「没有任何标志」，于是「这是切到输入法」还是「这只是窗口获得了焦点」
   只能靠「有没有第 0 枚标志」反推。焦点离开侧从 spec 091 起就有正向标志做
   同一件事。

3. **对称性只能靠人眼保证**。没有任何检查断言「同一 bit 编号在两侧代表同一语义维度」。
   有人给一侧单独加了第 2 枚标志、或者两侧第 1 枚含义不同，检查全绿，
   真机行为漂移。

## 目标

- 用**一张**协议表承载两侧的位标志，让「同一 bit 编号 = 同一语义维度」
  成为**可被逐行断言**的硬约束。
- 补齐焦点进入侧的正向标志，让「窗口获得焦点 / 应用失焦」可以被直接表达。
- 焦点进入 / 焦点离开两侧具备**对称的**判定口径。
- 协议的线格式**零变化**：新旧两端互相不认识时都安全降级。

## 非目标

- 不改变「切到输入法显示面板、切走输入法收起面板」的既有用户可感知行为。
- 不新增任何进程间消息类型，不改动命令号与字段布局。
- 不改变普通窗口焦点事件对服务端业务逻辑的影响（只更新界面与活动会话）。

## 功能需求

### FR-1 一张协议表

协议表由若干「槽位」组成，每槽位含：焦点进入侧位掩码、焦点离开侧位掩码、
语义维度名。**两侧位掩码必须相等**（同一 bit 编号），否则该表不合法。

当前表内容：

| bit | 语义维度 | 焦点进入侧 | 焦点离开侧 |
| --- | --- | --- | --- |
| 0 | 输入法激活状态 | 用户刚切到火流猩 | 用户刚切离火流猩 |
| 1 | 应用窗口焦点 | 窗口获得焦点 | 应用失去焦点 |

新增维度只能**加槽位**，不允许某一侧单独加标志。

### FR-2 焦点进入侧补齐正向标志

新增「窗口获得焦点」标志（bit1），与焦点离开侧的「应用失去焦点」标志成对存在。

### FR-3 两侧对称的判定口径

提供两个分类器，把「这次焦点事件属于哪一类」显式化：
焦点进入侧可区分「切到输入法 / 窗口获得焦点 / 未知」，
焦点离开侧可区分「切离输入法 / 应用失焦 / 未知」。

另提供两个与分类器同构的判定函数：
焦点进入侧「是否应当请求显示快捷面板」、焦点离开侧「是否应当收起快捷面板」
（后者为既有，本次保持不变）。

**未知**（旧端发零标志）必须落进「未知」类，且行为与今天**完全一致**。

### FR-4 两侧同时在场时取更具体的一侧

若焦点进入事件同时带「切到输入法」与「窗口获得焦点」两枚标志，
以「切到输入法」为准（更具体、信号更强）。

### FR-5 线格式零变化

命令号、字段布局、消息结构一律不变。旧端发零标志 ⇒ 判为「未知」⇒ 行为不变；
新端发第 1 枚标志给只认第 0 枚的旧端 ⇒ 旧端仍是旧语义。**双向安全降级。**

## 非功能需求

- 协议表与分类器必须是**共享纯函数**，生产代码与检查用例引用同一份实现。
- 协议表不得引入动态分配（表是编译期常量）。
- 用户可感知的行为**不发生变化**；若发生变化，必须在变更记录中显式说明。

## 验收标准

1. 协议表恰有 2 个槽位；每槽位两侧位掩码相等且均为单比特；维度名非空且互不重复。
2. 第 0 枚标志的取值与既有常量**逐字相等**（线格式零变化的回归保护）。
3. 第 1 枚标志在两侧成对存在，取值相等。
4. 两个分类器对「切到/切离输入法」「窗口获得/失去焦点」「零标志」「双标志同现」
   四类输入分别给出预期分类，且两侧分类互为镜像。
5. 焦点进入侧判定函数：带「切到输入法」为真；带「窗口获得焦点」或零标志为假。
6. 焦点离开侧判定函数：带「切离输入法」为真（无论常驻开关）；带「应用失焦」
   时与加标志之前的行为**完全一致**（尊重常驻开关）。
7. 线上可达：两种焦点进入事件在进程间传递时携带**不同的**标志值，
   服务端能据此区分（由集成用例证明）。
8. 产品构建零错误；全量检查套件全绿。

## 与其它变更的关系

- 依赖 spec 091 / ADR 0024 建立的焦点离开侧标志。
- 依赖 spec 094 / ADR 0025 建立的共享判定纯函数（协议表与它并列）。
- 与 spec 095 / ADR 0026（常驻开关收进统一设置面板）**无耦合**：
  两者都读「常驻开关」这个状态，但一个只管协议、一个只管界面入口。

# 091 · 快捷设置栏显隐跟随输入法激活状态；语言栏菜单去除「快速面板常驻」

- **状态**：已实现（代码 + 单测已落地，待真机复验）
- **日期**：2026-10-31
- **来源**：v1.1.5 真机验收（用户未重启状态下 7 条反馈 + 1 条新缺陷）
- **关联**：spec 080 / ADR 0008（切到火流猩时弹面板）、spec 084 / ADR 0013（常驻模式）、
  ADR 0016（FocusOut 焦点守卫）、ADR 0019（常驻勾选态持久化）、ADR 0022（默认常驻 + 扁平 idle alpha）

---

## 1. 用户可见的问题

### 1.1 新缺陷（US091-A，本轮主线）

从火流猩输入法切换到其他输入法后，**快捷设置栏仍然留在屏幕上**。

正确行为应与其他输入法一致：**切到火流猩 ⇒ 快捷设置栏显示；切到其他输入法 ⇒ 快捷设置栏不显示**。

### 1.2 改口项（US091-B，本轮附带）

v1.1.5 验收第 3 条「语言栏勾选态不回显」**不再按「补回显」处理**，
改为**从输入法（语言栏）弹出菜单里去掉「快速面板常驻」这一项**。

托盘图标右键菜单里的同名项**保留** —— 它是用户明确认可的取消入口（验收第 2 条：
「Alt+, 或托盘右键能取消常驻」判定为成功）。

## 4. 边界（明确不做）

1. **不改**「常驻」的含义：常驻 = 面板不因鼠标移开 / 切窗口 / 点击而消失；
   「切到别的输入法」属于**输入法本身不在场**，不属于常驻要保护的范围。
2. **不改**输入引擎行为（librime 不动）。
3. **不新增** IPC 消息类型（沿用既有消息 + 其既有参数槽位）。
4. **不修**托盘菜单的勾选态回显 —— 托盘菜单的勾选态本来就正常。
5. **不动** `output/install.nsi` 与 `output/data/user-custom/**`。
6. v1.1.5 验收第 6 条（右键屏蔽 → 名单落盘 → 托盘撤销）**本轮不处理**，
   仍是「待重启后复验」项。

## 5. 术语

- **快捷设置栏 / 快速面板**：同物，程序内实体名为 QuickPanel。
- **常驻态**：勾选了「快速面板常驻」时的模式，面板不自动消失。
- **瞬时态**：未勾选时的模式，面板按超时 / 鼠标离开规则自动收起。
- **输入法激活**：用户的活动输入配置切换到火流猩（而非仅仅是窗口获得焦点）。

# 084 - 快捷设置栏长显模式（常驻 + 悬停变清晰）

> 收口 spec 052（QuickPanel 长显模式）留下的真实缺口。关联 ADR 0013、清单 P-E3。

## 0. 背景

spec 052 在 2026-07-08 设计过「长显模式」，需求来自用户本人：

1. 切到火流猩输入法 → 快捷设置栏**自动常驻**在屏幕右下角
2. 常态只有**很淡的一层**（20% 不透明度）
3. 鼠标移上去 → 变**完全清晰**（100% 不透明度）
4. 鼠标移开 → 再淡回去

那份设计**从未落地**。今天的快捷设置栏只有一种形态：按需弹出 → 悬停只换图标颜色 → 鼠标离开
或失焦就消失。

同时 spec 080（切换到火流猩输入法时自动弹出快捷设置栏）**明确写了不做**长显，只做「瞬时
面板」。所以长显不是被否决，而是**从没被接上**。

## 1. 目标

- **G1** 用户能让快捷设置栏**常驻**在屏幕右下角，不必每次切换输入法都等它弹出来。
- **G2** 常驻态下，面板常态是很淡的一层，鼠标移上去变完全清晰，移开再淡回去。
- **G3** 常驻与否是用户可随时切换的开关，且开关状态一眼可见。
- **G4** 开关关闭时，一切与今天**完全一致**。

## 2. 用户故事

- **US084-A** [P1]: 用户在托盘菜单里打开「快捷设置栏常驻」，面板立刻出现在右下角并保持不消失。
- **US084-B** [P1]: 面板常驻时鼠标移上去，面板在约 1 秒内变清晰；移开后在约 1 秒内淡回很淡的状态。
- **US084-C** [P1]: 托盘菜单里该开关带勾选标记，勾着就表示常驻开着。
- **US084-D** [P1]: 用户再次点击该开关，面板收起并回到今天的「按需弹出」行为。
- **US084-E** [P2]: 开着常驻时，鼠标点面板里的按钮仍然有效（方案 / 短语 / 快捷键）。
- **US084-F** [P2]: 开着常驻时，切换到别的应用后面板不残留在别人的窗口上。

## 3. 功能需求

- **FR-001**: 面板整体透明度由一个「不透明度系数」控制；系数为满值时，渲染结果与今天逐像素一致。
- **FR-002**: 常态与悬停两种状态之间是**渐变**，不是瞬变。
- **FR-003**: 常驻模式下，面板不因鼠标离开、不因失去焦点、不因前台应用切换而自动消失。
- **FR-004**: 常驻模式下常态不透明度为 20%，悬停时为 100%。
- **FR-005**: 关闭常驻模式时，面板立即收起，不透明度系数复位为满值。
- **FR-006**: 托盘菜单提供一项可勾选的开关，简体 / 繁体 / 英文各有一条对应文案。
- **FR-007**: 常驻状态不写入注册表也不写入配置文件；输入法服务重启后回到默认（关）。
- **FR-008**: 菜单弹出时该开关的勾选状态反映真实状态。

## 4. 非目标

- 不改面板的尺寸、位置、图标、配色、圆角、渐变方向。
- 不改「切到火流猩输入法自动弹出面板」这条既有行为（spec 080）。
- 不改「按 Alt+, 弹出 / 再按收起」的既有行为。
- 不把常驻状态持久化到注册表或配置文件。
- 不做暗色主题下的透明度曲线。
- 不新增输入法进程与输入法服务之间的通信消息。

## 5. 验收标准

| ID | 标准 | 验证方式 |
|---|---|---|
| SC-001-1 | 打开开关后面板常驻不消失 | 真机：勾选后切到别的应用，面板仍在 |
| SC-001-2 | 悬停变清晰 / 移开淡回 | 真机目视 + 自动化用例钉住系数演算 |
| SC-001-3 | 菜单勾选状态正确 | 真机：开 / 关各一次，勾号跟随 |
| SC-001-4 | 关闭后行为与今天完全一致 | 自动化用例：系数为满值时渲染输入与今天逐字节相同 |
| SC-002-1 | 常驻态下面板按钮仍可用 | 真机：点「短语」能打开短语窗 |
| SC-003-1 | 编译零错误 | 整套解决方案构建通过 |
| SC-003-2 | 既有测试不回归 | 全套件通过 |

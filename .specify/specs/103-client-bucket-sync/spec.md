# 规格 103 · 客户端桶化同步（批次 BR-①g）

> **权威设计来源**：`docs/adr/0077-bucket-level-sync-storage-architecture.md`（下称「ADR 0077」，Status=Accepted，客户端段 **D12–D28**）。

> 真实名（表名 / 文件名 / 函数名 / 迁移脚本号）一律只写在 `plan.md` 与 `tasks.md`。
> **上游**：spec [102-bucket-level-sync-storage](../102-bucket-level-sync-storage/spec.md)（服务端先行批次 BR-①f，已部署生产）。
> **本文件与 ADR 0077 冲突时，一律以 ADR 0077 为准**；冲突登记在 §8，待拍板项登记在 §9。

## 1. 目标

把**客户端**的云同步调用从「**逐条端点**」改为「**桶级端点**」，并用**显式阶段状态机**驱动灰度，
使「老端点退役」成为**可验证、可回滚**的流程，而不是一次性切换。

- 现状问题（实测，见 ADR 0077 背景一节）：服务端索引行数 ≡ 词条数 ⇒ 一次全量首导 ≈ 10.9 万行写入，
  而每日免费写入额度为 10 万行且**按整库合计**计算，一旦耗尽，**该库内所有账号的所有写操作一起失效**
  （包括真实用户登录）。
- 服务端侧已完成桶化并**部署生产**（BR-①f，2026-11-25）：桶级端点已上线，生产冒烟 **9/9 PASS**。
  **但客户端仍走老端点** ⇒ 首导的写放大**尚未被消除** ⇒ 这是本批存在的唯一理由。
- 目标状态：客户端首导改走桶级端点 ⇒ 索引行数 ≈ **1,024**（替代 54,536，约 **53 倍**）；
  D1 实际写行数 ≈ **2,048**（替代 54,536，约 **27 倍**）⇒ 单日额度不再是约束。
- **本批只做客户端**：服务端**不改**。既有的逐条端点与逐条索引**逐字不动**，老客户端零感知。

**为什么必须做客户端**：服务端先行只是**把能力准备好**；不切客户端，写放大**一天都不会减少**。

## 3. 范围

**本批做**：
1. 客户端分桶：条目 → 桶的**确定性**归属（加密域派生，桶键为不透明标识）。
2. 桶包打包 / 拆包：既有条目级密文块**直接串接**，**不新增**桶级加密层。
3. 桶级时序分配：桶级时序取桶内条目时序最大值，并**严格大于**本地已存桶时序。
4. 桶内容指纹：与条目级侧车**同一语义口径**，使「桶内容没变」可判定。
5. 阶段状态机：五阶段 + 环境变量/侧车双来源的生效口径 + 阶段**可回写**。
6. 侧车升版：双编号空间并存 + 桶行 + 阶段位，且**必须能读上一版**。
7. 桶级响应解析：**独立**实现，按桶契约判字段。
8. 推送分批（每请求桶数上限）与拉取分页（页数上限按词典数动态计算）。
9. 超限降级：单桶超限时**该桶**退回逐条端点推，其余桶不受影响。
10. 切读阶段的部分恢复：云端视图缺失时强制重推所在桶。
11. 上述各项的自动化测试与门禁复现。

**本批不做**（完整清单见 `tasks.md` §8）：
- 服务端任何改动（桶端点、桶表、护栏口径、老端点下线）。
- 老端点**退役**（下线老端点本身属下一批，需用户单独授权）。
- 写预算护栏改「全局口径 / 按活跃账号分摊」（已拍板维持现状，不立项）。
- 是否升级付费存储额度（已拍板暂不升级）。
- 跨设备 `last_seen` 读路径附带写的占比治理。

## 4. 功能需求（FR）

| 编号 | 需求 | 依据 |
|---|---|---|
| FR-201 | 必须支持把一个词典的全部条目**确定性地**划分到固定数量的桶；同一条目在任何机器、任何轮次都落到同一桶 | ADR 0077 D15 / D23 |
| FR-202 | 桶标识必须是不透明派生值；**明文摘要派生不得使用**（可被字典穷举反推）；桶标识与条目身份必须用**不同**的派生密钥 | ADR 0077 D14 / 硬约束 1 |
| FR-203 | 桶包内容必须由**既有条目级密文块直接串接**构成；**不得**引入桶级随机串/桶级附注；条目级附注**逐字不变** | ADR 0077 D3 / D19 |
| FR-204 | 客户端必须以**桶级时序**向服务端上报，且上报值**严格大于**本地已存桶时序 | ADR 0077 D4 / D16 |
| FR-205 | 客户端必须能判定「桶内容未变」并据此**不推该桶**；判定口径必须与条目级侧车**同源**（语义指纹，剔除派生字段、保留学习次数） | ADR 0077 D17 |
| FR-206 | 桶内容必须是**合并后本地视图的全集**按 (词典名, 分片) 分组；不得只推变更条目 | ADR 0077 D18 |
| FR-207 | 必须支持**五个阶段**：逐条单跑 / 双写 / 双写加校验 / 只走桶 / 逐条退役；阶段**不得自动递增** | ADR 0077 D12 |
| FR-208 | 阶段生效口径必须是「外部环境变量优先、否则侧车值、否则默认逐条」；环境变量生效时必须**写回侧车** | ADR 0077 D12 |
| FR-209 | 必须能在**不改代码、不重装、不清数据**的前提下退回逐条端点（回滚 = 设环境变量为 0 跑一轮） | ADR 0077 D12 / 四段路线 |
| FR-210 | 本地状态文件必须升版，且**必须能读上一版**；读到上一版时行为必须与升级前**逐字等价** | ADR 0077 D13 |
| FR-211 | 本地状态文件必须同时承载**两套互不参照的编号空间**（逐条游标与桶游标），桶游标**强制从 0 起**、**不得默认沿用**逐条游标 | ADR 0077 D13 / D25 / AC-109 |
| FR-212 | 桶级响应解析必须**独立实现**并按桶契约判字段；**不得**复用逐条端点的响应解析器 | ADR 0077 D26 / AC-108 |
| FR-213 | 推送必须按「每请求桶数上限」分批；拉取必须按「每页桶数上限 × 单轮页数上限」分页，且单轮页数上限必须**按本地词典数动态计算** | ADR 0077 D20 / D27 |
| FR-214 | 单桶超条目数上限或超字节上限时，该桶**必须降级**走逐条端点推，且**不得**因此使整批失败 | ADR 0077 D21 |
| FR-215 | 切读阶段必须能检出「本地已同步但云端视图缺失」的条目，并**强制重推**其所在桶；该判定**仅在库存扫描完整时**生效 | ADR 0077 D28 / D10 |
| FR-216 | 全部用户可见的错误提示必须为简体中文；不得出现明文词条内容、词典名、令牌 | 宪法 P2 / P5 / ADR 0077 硬约束 1 |

## 6. 验收判据（AC，均为可判定式）

| 编号 | 判据（含数字） |
|---|---|
| **AC-201** | 分桶确定性：同一条目在同一密钥下**任何轮次、任何机器**都落到同一桶；改一条词条**只重写 1 个桶**（不重写整册）。判据：分桶函数对固定输入两次调用结果**逐字节相等**；单条目变更后受影响的桶数 = **1**。 |
| **AC-202** | 桶包透明性：桶包 = **N 个既有条目级密文块直接串接**；条目级附注**逐字不变** ⇒ 老密文在新协议里**逐条可验**。判据：同一批条目分别走逐条推送与桶推送后，**密文块逐字节相等**（逐条比对，不是只比条数）。 |
| **AC-203** | 分批参数：单轮页数上限 = **max(16, 词典数 × 11 + 2)**，且**不超过 32 页**（硬上限）；单请求桶数 ≤ **64**；单页桶数 ≤ **100**。判据：客户端常量与服务端契约常量**逐字相等**；单词典时页数 = 16；多词典时按公式算出的页数**大于**单词典的 16 页；词典数 ≥ 3 时页数**触到 32 页硬上限**（并在该情形下把「库存是否扫得完」列为待实测项，见 Q2）。 |
| **AC-204** | 写入量口径**两个都测**：(a) **索引行数** = 设备数 × 桶数 = **1,024**（替代 54,536，约 **53 倍**）；(b) **D1 实际写行数** ≤ **2 × 桶数** = **2,048**（替代 54,536，约 **27 倍**）。判据：两口径**分别**断言，不得只测其一。 |
| **AC-205** | 桶级时序守卫：同桶同内容再推 ⇒ 服务端**整桶跳过**（零写入）；桶内容变化但条目时序未变大 ⇒ 上报值**严格大于**已存值（否则真实变更会被整桶跳过）。判据：两种场景分别断言（跳过场景断言**零写入**；抬升场景断言上报值 > 已存值）。 |
| **AC-206** | 稳态零写：桶内容未变 ⇒ 该桶**不推**（连请求都不发）；桶内容变了 ⇒ 只推该桶。判据：连续两轮无变更 ⇒ 桶端点推送请求数 = **0**。 |
| **AC-207** | 桶级响应解析**独立**：桶响应字段集合 = {桶标识, 设备标识, 桶级时序, 桶密文, 条目数, 服务端序号}，**无随机串字段**；把桶响应喂给逐条解析器**必须失败**（证明确有独立实现）。判据：两条断言同时成立。 |
| **AC-208** | 回滚是**配置级**：设环境变量为 0 跑一轮 ⇒ 该轮**只走逐条端点**、桶端点请求数 = **0**；**不删**云端桶数据；**不改代码、不重装**。判据：三条断言同时成立。 |
| **AC-209** | 偏离登记完整：客户端段对服务端原文的**每一处偏离**都写明了「偏离什么 + 为什么」；**每桶条目数取值 / 对应桶数 / 单轮预估传输时长 / 客户端单次超时窗口**四项数值**全部出现在决策记录正文**，且未实测者**明确写「未判定 + 需要什么」**。判据：逐项核对决策记录文本。 |
| **AC-210** | 未开闸零行为变化：阶段 = 0 时，客户端的端点调用序列、状态文件语义与本批之前**逐字等价**；读到上一版状态文件 ⇒ 阶段 = 0、桶游标 = 0、无桶行。判据：两条断言同时成立。 |
| **AC-211** | 端到端往返：同一批条目走桶级推送后拉回，**解包后逐条可验**且条目集合与推送前**相等**；客户端全程**未**把桶包当条目包解析。判据：本地全链路复现。 |
| **AC-212** | 真机判据（**未实测前记「未判定」**）：真实词典的桶包字节数抽样 + 单桶写入实测耗时 ⇒ 才能判定是否落在客户端单次超时窗口（**30 s**）内。**当前状态 = 未判定**（需要什么：真实词典抽样 + 生产吞吐实测），**不得**用推算值记为已达成。 |
| **AC-215** | 每轮桶推行数配额（**单一真相源**：实现常量 = 头文件注释 = ADR 0077 D29 = 本条，四处**逐字相等**）：单轮桶推送的 **D1 写行预算 = 2,000 行**（当前实现值；候选 4,096 / 8,000 **待用户拍板**，改值须重出包装机）；超限的桶**整桶延到下一轮**（按声明序累加、**不插队、不截断单桶**）；配额命中时必出诊断行 `bucket quota ... quota_rows=<行数>`。判据：① 常量与注释逐字相等；② 被配额截断的桶**下一轮被重新选中**（不丢桶）；③ 诊断行给出本轮实际行数。**注**：**AC-213 / AC-214 为永久退役的悬空引用**（从未定义），不得引用；真机判据是 **AC-212**。 |

## 7. 合规红线与不变量（本批必须遵守）

1. **端到端不变量**：服务端只见密文；客户端**不得**把明文词条内容、词典名写进桶标识或任何日志。
2. **条目级加密附注逐字不变** ⇒ 老密文在桶协议里仍可逐条验证。
3. **桶级不做二次加密、不引入桶级随机串**（ADR 0077 D3 已否决）。
4. **桶级与条目级两套时序必须同时存在**；只留其一必然回退或乒乓。
5. **阶段不得自动递增**；每次跃迁必须有人工判据。
6. **中文用户可见字符串**（宪法 P2 / P5）。
7. **入库、部署、生产迁移均需用户授权**；本批文档轮不执行任何写操作。
8. **词典子模块不得入库**；未跟踪的构建产物与取证报告目录按红线不提交。
9. **单一真相源**（宪法 R7）：阶段、桶粒度、指纹口径、编号空间四处概念**只有一份定义**。

## 8. 与 spec 102 / ADR 0077 的关系与偏离（**一律以 ADR 0077 为准**）

| # | 上游口径 | 本批口径 | 依据 |
|---|---|---|---|
| 1 | spec 102 §9 **Q1**：固定 64 分片（64 桶 / 每桶 ≈852 条）与「每桶 64 条」（852 桶）互斥待拍板 | **已拍板**：选「每桶条目数」层为口径；「64」= 一级分片数，其下再分二级 16 片 ⇒ **1024 桶 / 词典**；每桶 ≈ **53** 条；首导索引行数 **1,024**（约 53 倍） | ADR 0077 D23 |
| 2 | ADR 0077 D2：分片用**明文**摘要派生 | **偏离**：改用**加密域**摘要字节 + 独立派生标签 ⇒ 明文摘要可被字典穷举反推「哪个词条落在哪个桶」 | ADR 0077 D14 + 偏离登记 |
| 3 | ADR 0077 D2：固定 64 个一级分片 | **偏离**：64 × 16 = 1024 桶 ⇒ 桶更小、单包写入更快 | ADR 0077 D15 / D23 + 偏离登记 |
| 4 | ADR 0077 D6：侧车升版并**强制重置逐条游标为 0** | **偏离**：逐条游标**保留**给老端点、另设**独立**桶游标从 0 起 ⇒ 四段渐进退役期间老端点仍活跃，重置会致老端点全量重拉重写 | ADR 0077 D13 / D25 + 偏离登记 |
| 5 | ADR 0077 D9：默认桶大小取 64 条 ⇒ 852 桶 | **偏离**：「64」是**分片数**不是每桶条目数上限（D2 与 D9 混用两个层级，见 Q1）；D9 的「64 条/桶 ≈ 7.5 s」作为**推算档位**仍成立 | ADR 0077 D23 + 偏离登记 |
| 6 | ADR 0077 D9：单轮拉取覆盖 64 桶 | **偏离**：单页 ≤ **100** 桶、单轮页数按**词典数动态计算** ⇒ 固定页数在多词典时扫不完库存 ⇒ 永久压制推送 | ADR 0077 D20 / D27 |

## 1. 任务目标（一句话）

让用户用一个火流猩账号，把**自己造出来的输入法资产**（个人词库、用户短语、个人配置）安全地存到云端，
并在他自己的多台设备之间自动保持一致 —— 不让这些资产只活在一台机器上。

## 2. 用户故事

| # | 故事 | 验收一句话 |
|---|---|---|
| **US1** | **注册与登录**：我想用邮箱 + 密码登录火流猩账号 | 输入邮箱密码后能登录成功；密码错误有明确中文提示，不静默失败 |
| **US2** | **一次登录，长期免登**：我不想每次开机都输密码 | 登录一次后，重启系统 / 重启输入法服务仍保持登录；令牌过期自动续期，用户无感 |
| **US3** | **词库跨设备**：在公司电脑造的词，在家里电脑能打出来 | A 设备新增词条后，B 设备同步完成即可打出该词 |
| **US4** | **短语跨设备**：A 设备的用户短语在 B 设备可见 | A 设备新增短语后，B 设备同步完成即可在短语界面看到 |
| **US5** | **配置跨设备**：快捷键、样式、方案补丁在多端一致 | A 设备改快捷键并同步后，B 设备同步完成即生效 |
| **US6** | **离线照常用**：没网也能正常打字 | 断网时全部本机功能照常，无卡顿、无报错弹窗、无重试风暴；恢复网络后自动补同步 |
| **US7** | **云端只见密文**：我不希望云端能读到我的词库 | 云端保存的内容在抓包与存储侧均为密文；没有账号口令无法还原出明文 |
| **US8** | **两端同时改不丢输入**：两台设备同时改同一份数据 | 冲突后两边最终一致，且**双方各自的改动都保留**（按条目合并，不整份覆盖） |
| **US9** | **一键退出与清空**：我要能随时停止同步并清掉云端数据 | 登出后本机数据保留、云端数据可一键清空；清空后云端确实没有可恢复的内容 |
| **US10** | **不拖慢打字**：同步不能影响输入手感 | 同步全程在后台，输入延迟与上屏耗时与未开启同步时无可感知差异 |
| **US11** | **换机 / 重装不丢**：我换电脑了，东西还在 | 新设备登录同一账号后，同步恢复出词库 / 短语 / 配置 |
| **US12** | **不用也能用**：我不需要云功能 | 不登录时软件行为与现在完全一致，零出向请求 |

## 3. 范围

### 3.1 同步清单

| 数据项 | 同步 | 粒度 | 冲突合并方式 |
|---|---|---|---|
| 个人配置（个性化后的配置、样式、方案补丁） | ✅ | 文件级 | 整份按版本取新（版本相同则以设备标识定序） |
| 用户短语 | ✅ | 条目级 | **按条目合并**，条目自带版本，取新 |
| 个人词库 | ✅ | 条目级 | **按条目合并**，条目自带版本，取新 |
| 输入历史 / 上屏内容 | ❌ | — | 隐私红线，永不离开本机 |
| 临时状态（当前输入、会话状态） | ❌ | — | 无业务价值 |
| 操作系统相关设置（显示器、缩放、语言） | ❌ | — | 各机自定 |
| 方案本体（第三方词库包） | ❌ | — | 只同步用户对方案的**改动**，不搬运方案文件本体 |

### 3.2 账号的边界

账号**只用于同步**。不用于社区、排行榜、广告、行为统计、内容分发；不因登录而上传任何输入内容。

### 3.3 首版明确不做

- 不做「找回密码」（口令丢失即无法解密云端数据，只能重置账号并清空云端 —— 此事实必须在界面上写清楚）。
- 不做「修改密码」（口令变更会牵动全量数据重新加密，首版不做）。
- 不做输入历史的跨设备回看。
- 不做网页端管理云端数据（首版只有桌面端）。
- 不做团队 / 家庭组织账号。

## 4. 功能需求

| # | 需求 |
|---|---|
| **FR-001** | 支持邮箱 + 密码注册与登录；注册需通过邮箱验证码确认归属。 |
| **FR-002** | 登录成功后自动保存续期凭据，用户重启后仍保持登录；续期失败才要求重新输入密码。 |
| **FR-003** | 密码与口令派生只在客户端完成；**明文密码不离开客户端内存**，用后立即清零。 |
| **FR-004** | 客户端生成两把互相独立的密钥：**登录用**与**加密用**；加密用密钥永不上传。 |
| **FR-005** | 同步内容一律**加密后上传**；云端存储与传输链路中都是密文。 |
| **FR-006** | 每个数据项带**版本号**（时间 + 序号 + 设备标识），用于跨设备定序，不依赖各机时钟一致。 |
| **FR-007** | 拉取时按「上次同步到的位置」增量拉取，不做全量重传。 |
| **FR-008** | 词库与短语的冲突按**条目**合并：同一条目取版本较新者，不同条目取并集。 |
| **FR-009** | 配置文件的冲突按整份取版本较新者。 |
| **FR-010** | 合并由**客户端**完成：客户端拉下远端密文、解密、与本地按条目合并、再把合并结果加密上传。 |
| **FR-011** | 同步触发：启动时拉一次；本地有变更时延迟一小段时间后自动上传；用户可随时点「立即同步」。 |
| **FR-012** | 同步全程**不阻塞输入**：不在输入处理线程上做网络与磁盘 I/O。 |
| **FR-013** | 网络不可用时静默降级：本机功能不受影响，不排队堆积，恢复后自动补同步。 |
| **FR-014** | 登出：清除本机凭据与加密密钥，**保留本机数据**；云端数据不清除（清空是另一条独立操作）。 |
| **FR-015** | 提供「清空云端数据」入口，执行前二次确认并明确告知不可恢复。 |
| **FR-016** | 界面可见：账号页可查看登录状态、账号邮箱、设备列表（可移除设备）、最近一次同步时间与结果。 |
| **FR-017** | 同步失败只以「状态 + 中文原因」呈现，不弹打断式错误框。 |
| **FR-018** | 未登录状态下，任何同步相关操作都不可达，出向请求数为 0。 |
| **FR-019** | 同一账号可登录多台设备；设备可被用户从列表中移除（移除后该设备的续期凭据失效）。 |
| **FR-020** | 单次同步的数据量有上限；超过上限按批次传输并给出进度。 |

## 5. 非功能需求

| # | 需求 |
|---|---|
| **NFR-001** | **不新增常驻进程**：同步能力挂在既有唯一常驻进程内。 |
| **NFR-002** | 常驻内存仍 < 40 MB；空闲 CPU 仍 < 0.1%（单核）。 |
| **NFR-003** | 输入延迟与上屏耗时在开启同步后无可感知变化。 |
| **NFR-004** | **不新增第三方依赖**：加密与网络能力用操作系统自带能力实现，不引入外部库。 |
| **NFR-005** | 不改动引擎子模块，不改引擎行为。 |
| **NFR-006** | 用户可见文案保持简体中文。 |
| **NFR-007** | 服务端不得留存明文口令；不得把同步内容与设备标识、输入行为关联成画像。 |
| **NFR-008** | 密钥与凭据在本机以系统凭据保险箱保护；日志与崩溃信息中不得出现口令、密钥、词库明文。 |
| **NFR-009** | 同步协议向后兼容：旧版本客户端连上新版服务端不得导致数据损坏。 |

## 6. 验收标准

| # | 用例 | 通过条件 |
|---|---|---|
| **AC-01** | 注册 → 登录（US1） | 邮箱验证码通过后注册成功；密码错误有中文提示且不进入登录态 |
| **AC-02** | 免登（US2） | 登出后重新登录一次，重启系统与输入法服务仍为登录态，续期自动完成 |
| **AC-03** | 双机词库（US3） | A 加词 → 同步 → B 同步完成 → B 能打出该词，且 B 端该词可继续累积词频 |
| **AC-04** | 双机短语（US4） | A 加短语 → B 同步完成 → B 的短语界面可见同一条 |
| **AC-05** | 双机配置（US5） | A 改快捷键 → B 同步完成 → B 生效 |
| **AC-06** | 断网降级（US6） | 断网期间打字、上屏、本机设置全部正常；无重试风暴；恢复网络后自动补同步 |
| **AC-07** | 密文校验（US7） | 服务端存储与传输抓包中均无明文词条 / 短语 / 配置内容；无口令时无法还原 |
| **AC-08** | 并发编辑（US8） | A、B 同时改不同条目 → 同步后两端条目集为并集，且两端一致 |
| **AC-09** | 并发改同一条目（US8） | 两端改同一条目 → 最终两端取同一个版本，不出现「两端永远不一致」 |
| **AC-10** | 登出与清空（US9） | 登出后本机数据仍在、云端仍在；「清空云端数据」后服务端确实没有可恢复内容 |
| **AC-11** | 性能（US10 / NFR-001~003） | 三数字（1 进程 / < 40 MB / 空闲 < 0.1%）实测未破线；输入延迟无可感知变化 |
| **AC-12** | 未登录零请求（US12 / FR-018） | 未登录状态下全流程出向请求数 = 0 |
| **AC-13** | 换机恢复（US11） | 新设备登录后同步恢复出词库 / 短语 / 配置 |
| **AC-14** | 设备移除（FR-019） | 从列表移除设备后，该设备续期请求被拒绝 |

## 7. 合规红线

1. **输入内容永不上云**：只有用户自己造出来的资产进入同步管道。
2. **云端不见明文**：同步内容在离开客户端前已加密（US7 / FR-005 / NFR-007）。
3. **默认关**：不登录即零出向请求，不新增常驻进程，不影响输入热路径。
4. **不自造遥测**：不埋点、不上报崩溃、不做行为统计。
5. **不碰第三方端点**：不得把任何第三方的服务器当作同步目标（与 spec 098 的黑名单条款同口径）。
6. **离线优先**：任何网络故障都不允许阻断本机使用。

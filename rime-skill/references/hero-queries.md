## 混淆例（可能误命中，需人工判别）

| # | 查询 | 判别要点 |
|---|---|---|
| 1 | "rime 怎么和别的工具集成" | 若是编辑器/IME 集成 → 可能属 `Rime-in-Emacs` 专题；仍与本技能相关 |
| 2 | "输入法词库怎么导出成 csv" | 词典管理 → 命中本技能 |
| 3 | "rime 皮肤" | 外观定制 → 命中本技能（前端层） |
| 4 | "我的输入法打不出字了" | 先排错 → 命中；若是引擎崩溃 → 跳出 |

## 维护规则

1. resolver 误命中 → 收紧 `description` 与 `triggers`，把误命中的查询加进负例表；
2. resolver 该命中没命中 → 在 `description`/`triggers` 补关键词，并把查询加进正例表；
3. 新增兄弟技能后，重跑本表检查**行动上的干扰**（description 抢词）；
4. `description` 保持 ≤50 词、≤1024 字符，且以 `Use when` 开头。

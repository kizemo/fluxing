# Chapter 8: 前端外观与发布

## Core Idea

前端（librime 之外的平台相关部分）负责显示与系统交互，外观定制走**前端自己的 `.custom.yaml`**（`weasel.custom.yaml` / `squirrel.custom.yaml`），与方案层分开。

## Reference Tables：外观设置归属

| 想改什么 | 文件 | 归属 |
|---|---|---|
| 候选栏字体字号 | `weasel.custom.yaml` / `squirrel.custom.yaml` | 前端 |
| 配色方案 | 同上 | 前端 |
| 候选横排 / 内嵌编码 | `weasel.custom.yaml` | 前端（`inline_preedit` 仅 TSF） |
| 托盘图标 | `weasel.custom.yaml` | 前端 |
| 方案选单内容 | `default.custom.yaml` | 方案层（`schema_list`） |
| 每页候选数 | `default.custom.yaml` | 方案层（`menu/page_size`） |
| 唤出选单的快捷键 | `default.custom.yaml` | 方案层（`switcher/hotkeys`） |

> ibus 用户注意：`ibus_rime.custom.yaml` **不含**配色、字体字号等外观项。

## Code Examples

### 小狼毫：字体字号与配色

```yaml
# weasel.custom.yaml
patch:
  "style/font_face": "明兰"      # 字体名，从系统字体对话框抄
  "style/font_point": 14         # 字号只认数字

  "style/color_scheme": starcraft
  "preset_color_schemes/starcraft":
    name: 星際我爭霸／StarCraft
    author: Contralisk <contralisk@gmail.com>
    text_color: 0xccaa88              # 编码行文字色，24 位，顺序是蓝绿红 0xBBGGRR
    candidate_text_color: 0x30bb55    # 候选项文字色
    back_color: 0x000000              # 底色
    border_color: 0x1010a0            # 与底色相同即无边框
    hilited_text_color: 0xfecb96      # 高亮文字（当前高亮候选对应的输入码）
    hilited_back_color: 0x000000
    hilited_candidate_text_color: 0x60ffa8
    hilited_candidate_back_color: 0x000000
```

配色工具：小狼毫 `https://bennyyip.github.io/Rime-See-Me/`、鼠鬚管 `https://gjrobert.github.io/Rime-See-Me-squirrel/`。

### 小狼毫：布局与托盘

```yaml
# weasel.custom.yaml
patch:
  style/horizontal: true         # 候选横排
  style/inline_preedit: true     # 内嵌编码（仅 TSF 支持）
  style/display_tray_icon: true  # 显示托盘图标
```

### 鼠鬚管：配色与外观

```yaml
# squirrel.custom.yaml（0.9.6 起支持配色方案）
patch:
  style/color_scheme: aqua
  style/horizontal: true
```

## Reference Tables：发布流程（维护者视角）

### 小狼毫 weasel

1. 记录主要更新内容（供更新日志）；
2. 检查 `weasel.yaml` 版本号；
3. `clog` 生成变更记录，手写「主要更新」段落格式须与自动生成段一致；
4. `update/bump-version.sh 0.10.0 0.11.0` 更新程序版本号；
5. push 后 CI 构建安装包，**测试全新安装 + 从上一版本升级**；
6. 打 tag 触发发布；
7. `update/write-release-notes.sh` 生成 `release-notes.html`；
8. 用 Hexo 更新官网 `rime.im`（下载按钮、下载页版本号与链接、更新日志、`appcast.xml` 推送频道）；
9. 0.9 旧更新频道另需推 `rimeime.github.io`。

### 鼠鬚管 squirrel

1. 更新 `squirrel/data/squirrel.yaml`；
2. `package/bump_version` → push 提交与版本 tag（tag 触发 GitHub Actions 构建）；
3. 在 GitHub Releases 编辑并发布，下载 zip 归档；
4. 私钥放 `squirrel/package/sign/`（**自动更新签名私钥由 Rime Keyholder 持有**）；
5. 从 CI 日志取 sha256 → `make sign-archive checksum=…` 生成 `appcast.xml`；
6. 更新官网更新日志与下载链接，用 `hexo server` 本地验证后 `hexo deploy`。

### 配方（℞）分发

配方是 plum 支持的 Rime 数据分发形式，可在全新用户文件夹还原自定义配置（用户词典数据需另行同步）：

```bash
recipes=(
  :preset
  ipa
  emoji
  custom:clear_schema_list
  custom:add:schema=terra_pinyin
  custom:set:config=squirrel,key=style/color_scheme,value=aqua
  custom:set:config=squirrel,key=style/horizontal,value=true
)
bash rime-install "${recipes[@]}"
```

官方配方包：<https://rime.im/recipes/>

## Anti-patterns

- **把外观设置写进方案 `.custom.yaml`** —— 外观是前端配置，写错地方不生效。
- **字号写「五号」「小五」** —— 只认数字。
- **色值写成 RGB 顺序** —— Rime 用 `0xBBGGRR`（蓝绿红）。
- **在 ibus 上找配色设置** —— `ibus_rime.custom.yaml` 没有外观项。
- **配色方案只改 `style/color_scheme` 而不定义 `preset_color_schemes/<名>`** —— 指向不存在的方案。
- **改前端文件时不分 TSF 与旧版** —— `style/inline_preedit` 只在 TSF 有效。

## Key Takeaways

1. 外观归前端、行为归方案——先分清再动手。
2. 配色是「名字 + 定义」两处都要写。
3. 字号只认数字，色值是 `0xBBGGRR`。
4. 发布是「版本号 + 变更记录 + CI 产物 + 官网 + 推送频道」一条链。
5. 配方能让别人一键还原你的配置，但不含用户词典数据。

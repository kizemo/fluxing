# Chapter 3: 定制处方集

## Core Idea

Rime 官方把定制集中成「9 个例子 + DIY 处方集」。这一章是**照抄级**的：每个例子都标明**改哪个文件**、**补靪怎么写**、**怎么验证**。完整片段见 [references/cookbook.md](../references/cookbook.md)。

## Code Examples

### 简体输出：为什么内置【简化字】要用另一个开关名

```yaml
# luna_pinyin.custom.yaml
patch:
  switches:
    - name: ascii_mode
      reset: 0
      states: [ 中文, 西文 ]
    - name: full_shape
      states: [ 半角, 全角 ]
    - name: simplification
      reset: 1                # 默认开启繁→简
      states: [ 漢字, 汉字 ]
```

**原理**：`simplifier`（繁简转换）必须配 `uniquifier`（同字去重），否则「鐘→钟」「鍾→钟」会出两个一样的候选。

**为什么【简化字】方案用 `zh_simp` 而不是 `simplification`**：切换输入方案时，**没有显式 `reset` 的开关会保留上一个方案的状态**。【朙月拼音】不重置 `simplification` 是因为「换编码方式 ≠ 换输出字形」；但【简化字】的语义就是「切到这里就要简体」，用独立开关名 + `simplifier/option_name: zh_simp` 才不会污染别的方案。

### 快捷键：格式与修饰符

```yaml
patch:
  "switcher/hotkeys":
    - "Control+s"
    - "Control+grave"     # 与 IBus 一致，不是 Ctrl+`
    - F4
```

- 格式：`修饰符+修饰符+…+按键名`，**加号必须写**；
- 修饰符：`Release`（松开时）、`Shift`、`Control`、`Alt`（Windows 上 Alt+字母被系统菜单抢走）、Linux 的 `Super`/`Meta`；
- 按键名：大小写字母数字用其自身，其余去 `XK_` 前缀（查 librime 的 `keysymdef.h`）；
- 修饰符顺序固定：**Shift → Control → Alt**。

### 模糊音：新写法（朙月拼音配置已重构）

```yaml
patch:
  speller/algebra:
    __patch:
      - pinyin:/zh_z_bufen      # zh/z 不分
      - pinyin:/n_l_bufen       # n/l 不分
      - pinyin:/hu_f_buhun      # hu/f 不昏
      - pinyin:/en_eng_bufen    # en/eng 不分
      - pinyin:/abbreviation          # 简拼
      - pinyin:/spelling_correction   # 拼写纠错
      - pinyin:/key_correction        # 按键纠错
```

老写法是在 `speller/algebra` 里直接插入模糊音规则行（模板 gist: 2320943），吴语模板 gist: 2015335。双拼/粤拼可照此思路改写 `speller/algebra`。

### 中西文切换键的 4 种临时切换策略

`inline_ascii`（临时西文区，回车上屏后自动复位）/ `commit_text`（已输入候选上屏并转西文）/ `commit_code`（已输入编码上屏并转西文）/ `noop`（屏蔽该键）。

## Anti-patterns

- **重定义 `/` `+` `=` 用路径连写** —— 这些字符在节点路径里有特殊含义，必须直接覆盖 `punctuator/half_shape` / `full_shape` 节点。
- **在 `punctuator` 里指望 Shift 生效** —— Punctuator 用 **unshifted ASCII** 作映射键，对 Shift 不感知；Shift+标点必须用 `key_binder` 拦截。
- **一个 `.custom.yaml` 写两个 `patch:`** —— 后者覆盖前者。
- **只改 `punctuator/half_shape` 不重述 `__include`** —— patch 静默失效（见 ch02）。
- **给 `simplifier` 不配 `uniquifier`** —— 同字候选重复。
- **用 emoji 老配置法** —— 已过时，改用 `github.com/rime/rime-emoji`。
- **想「用别的方案但保持简体」而改共享开关** —— 会污染别的方案，要用独立开关名。

## Key Takeaways

1. 改设置先问「全局还是单方案」→ 决定 `default.custom.yaml` 还是 `<schema>.custom.yaml`。
2. 列表类配置（`schema_list`、`key_binder/bindings`）要么整表替换，要么用 `/+` 追加。
3. 开关类配置要意识到**跨方案继承**，必要时显式 `reset` 或另起开关名。
4. 标点 = `punctuator`（不感知 Shift）+ `key_binder`（拦截 Shift+键）两层配合。
5. 任何改动都要问一句：**这个节点的源头是 `__include` 吗？**

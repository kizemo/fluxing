# Chapter 5: 拼写运算

## Core Idea

拼寫運算是 Rime 的独门绝活：**按规则改写编码**，用「一份词典 + 一套映射」造出多个输入方案。模糊音、简拼、容错、双拼、按键纠错、编码回显美化，全是它的算式。

## Key Concepts

| 术语 | 含义 |
|---|---|
| 编码 | 用于检索目标的字母序列（词典里的形式） |
| 输入码 / 拼写 | 用户实际敲的字符串，**可能不等于编码** |
| 拼写法（正字法） | 有效拼写集合 → 编码集合的映射 |
| 拼寫運算 | 以拼写为运算元的一元运算：字符串匹配 + 替换 |
| 投影 | 连续执行一组运算，每轮得到新的拼写法（拼写 ↔ 编码的映射） |
| 音节表 | 方案中所有编码的集合。拼音方案里它是固定集合；形码方案里不固定 |

**为什么需要它**：绝大多数编码方案不会用尽编码空间，空位就在那里。简拼、容错码就是从这些空位里「长出来」的——而规则跟编码方案的语言学原理绑定，所以只有引擎自己能生成。拼写运算提供了**描述这类产生式规则的能力**。

## Reference Tables：6 个算子

| 算子 | 格式 | 语义 | 例 |
|---|---|---|---|
| **xlit** 轉寫 | `xlit/<左字母表>/<右字母表>/` | 逐字符替换，左右字母表等长 | `xlit/abc/ABC/` → `abracadabra` ⇒ `ABrACAdABrA` |
| **xform** 變形 | `xform/<模式>/<替换式>/` | 匹配则改写，不匹配保持不变 | `xform/^([nl])ue$/$1ve/` → `nue` ⇒ `nve` |
| **erase** 消除 | `erase/<模式>/` | 完全匹配则从有效集合中删除 | `erase/^.*\d$/` → 带调拼音不可用 |
| **derive** 派生 | `derive/<模式>/<替换式>/` | 派生后**新旧拼写都有效** | `derive/^([nl])ue$/$1ve/` → `nue` 与 `nve` 都能查到 `lue` |
| **fuzz** 模糊 | `fuzz/<模式>/<替换式>/` | 派生 + 获得「模糊」属性：可作构词简码，**不用于单字** | `fuzz/^([a-z]).+([a-z])$/$1$2/` |
| **abbrev** 縮略 | `abbrev/<模式>/<替换式>/` | 派生 + 获得「縮略」属性：音节切分时区别处理 | `abbrev/^([a-z]).+$/$1/` |

**格式细节**：`<运算子><分隔符><参数1><分隔符><参数2>…`，分隔符是单个 ASCII 字符（通常用 `/`）。**分隔符不能出现在参数里**，且**不支持用 `\` 转义分隔符**（与 Perl 的 `s/\//\\/` 不同）。参数不含空格时可省略分隔符：`xlit abc ABC`。

**匹配语义差别**：`erase` 是**完全匹配**（regex match）；`xform` / `derive` / `abbrev` 是**部分匹配**（regex search/global replace）。

**`xlit` 的特殊之处**：它是唯一把运算元与参数按 **UTF-32**（而非 UTF-8）处理的算子——所以字母表可以用 ASCII 以外的字符，长度按 Unicode 字符数计。

## Code Examples

### 朙月拼音默认的简拼与容错

```yaml
speller:
  algebra:
    - abbrev/^([a-z]).+$/$1/          # 简拼（首字母）
    - abbrev/^([zcs]h).+$/$1/         # 简拼（zh, ch, sh）
    - derive/^([nl])ve$/$1ue/         # nue = nve, lue = lve
    - derive/ui$/uei/                 # guei = gui...
    - derive/iu$/iou/                 # jiou = jiu...
    - derive/([aeiou])ng$/$1gn/       # 容错 dagn = dang...
    - derive/ong$/on/                 # 容错 zhonguo = zhong guo
    - derive/ao$/oa/                  # 容错 hoa = hao...
    - derive/([iu])a(o|ng?)$/a$1$2/   # 容错 tain = tian...
```

### 模糊音（zh=z, ch=c, sh=s, n=l, en=eng, in=ing）

```yaml
speller:
  algebra:
    - derive/^([zcs])h/$1/
    - derive/^([zcs])([^h])/$1h$2/
    - derive/^n/l/
    - derive/^l/n/
    - derive/([ei])n$/$1ng/
    - derive/([ei])ng$/$1n/
    # 模糊音定义先于简拼定义，可令简拼支持以上模糊音
    - abbrev/^([a-z]).+$/$1/
    - abbrev/^([zcs]h).+$/$1/
```

**顺序有意义**：模糊音写在简拼之前，简拼才「继承」模糊音。

### 编码回显美化

```yaml
# 倉頡：用日月金木水火土显示编码区
translator:
  preedit_format:
    - xlit|abcdefghijklmnopqrstuvwxyz|日月金木水火土竹戈十大中一弓人心手口尸廿山女田難卜符|

# 朙月拼音：把 v 显示成 ü
translator:
  preedit_format:
    - xform/([nl])v/$1ü/
```

## Reference Tables：双拼怎么对接朙月拼音词典

双拼不自带词典，它靠 `xlit`/`derive` 把双拼码映射回全拼，从而复用朙月拼音的码表和用户词典。

```yaml
# 以「自然码双拼」为例的形状（各方案映射表不同）
speller:
  algebra:
    - xlit/.../.../          # 双拼字母 → 全拼字母
    - derive/.../.../
```

改写要点：先用 `xlit` 做字母级转写，再用 `derive` 处理需要保留原形的特例（如 `ue`/`ve`、零声母）。

## Anti-patterns

- **把 `derive` 当 `xform` 用** —— `derive` 会让新旧拼写同时有效（这是简拼/容错的关键）；想要「只有改写后有效」用 `xform`。
- **在 `fuzz` 派生出的拼写上指望能输单字** —— `fuzz` 标记的拼写只用于构词；要禁单字需配 `translator/strict_spelling: true`。
- **算式里用 `\` 转义分隔符** —— 不支持。
- **模糊音定义写在简拼之后** —— 简拼不会继承模糊音。
- **`xlit` 左右字母表长度不等** —— 会错位。

## Key Takeaways

1. 拼写運算改的是「用户敲的拼写 → 词典里的编码」这一步。
2. 六个算子：`xlit` 转写、`xform` 变形、`erase` 消除、`derive` 派生、`fuzz` 模糊、`abbrev` 縮略。
3. `derive` 与 `xform` 的区别是「新旧是否同时有效」——这一条决定简拼能不能用。
4. 算式顺序即优先级：模糊音在前、简拼在后。
5. 投影把算式作用到整个音节表上，编译期就完成，运行时零成本。

# Chapter 4: 方案与词典体系

## Core Idea

一个输入方案 = **配置文件**（控制引擎行为）+ **词典**（编码 ↔ 候选的对应）。引擎的四组组件（processors / segmentors / translators / filters）决定了方案能做什么。

## Reference Tables

### 引擎四组组件

| 组件 | 职责 | 关键点 |
|---|---|---|
| **processors** | 解释按键、生成编码串 | 组合键与修饰键状态 |
| **segmentors** | 切分编码（音节/词） | `abc_segmentor` 等 |
| **translators** | 查词典、合并排序、组词造句 | `table_translator`（码表）/ `script_translator`（脚本） |
| **filters** | 候选后处理 | `simplifier`（繁简）、`uniquifier`（同字去重）、`emoji`、`simplify` |

### translator 常用开关（改配置高频）

| 配置项 | 作用 |
|---|---|
| `translator/dictionary` | 用哪个词典 |
| `translator/enable_completion` | 逐键提示（关掉只出精确匹配） |
| `translator/enable_user_dict` | 用户词典与字频调整 |
| `translator/enable_sentence` | 码表连打（造句）——只对 `table_translator` 有效 |
| `translator/packs` | 词典扩展包列表 |
| `translator/preedit_format` | 编码区显示格式（可用拼写运算改写） |
| `translator/strict_spelling` | 限定「模糊」拼写不用于单字 |

### 词典文件格式

```yaml
# <name>.dict.yaml
---
name: luna_pinyin
version: '1.0'
sort: original
use_preset_vocabulary: false
import_tables:
  - luna_pinyin
...

# 单字
的	di5
# 词组
你好	ni3 hao3
```

- `---` 到 `...` 之间按 YAML 解析，**之后**是码表正文；
- 正文 **Tab 分隔**三列：文字、编码、频次；
- 编码是码表定义的**完全形式**，多音节间用空格；
- 版本号**加引号**（`0.10` 会被解析成数值 `0.1`）。

### 词典扩展包（librime ≥ 1.6.0）

- 固态词典 = `*.table.bin`（码表数据）+ `*.prism.bin`（音节表 + 拼写规则）；
- 扩展包 = 额外生成的 `*.table.bin`，**音节表必须与主词典一致**；
- 方案里用 `translator/packs` 列包名，多表并用。

```yaml
translator:
  dictionary: luna_pinyin_packs
  packs:
    - sample_pack
```

**风险**：librime 没有机制保证扩展包与主词典兼容，**二进制扩展包不宜脱离主词典分发**。

## Reference Tables：内置方案速查

| 方案 | 编码特点 | 注意 |
|---|---|---|
| 朙月拼音 | 全拼，默认方案 | 词典是繁體词库；`\` 键起手反查五笔画（需装【五笔画】） |
| 語句流 | 语句输入按键习惯 | 回车整句上屏，**不能用回车直接上屏编码** |
| 双拼（自然码/MSPY/智能ABC/小鹤/拼音加加） | 两键一音节 | 靠拼写运算对接朙月拼音词典；与朙月拼音**共享码表和用户词典** |
| 宫保拼音 | 多键并击，一击一音节 | 源自西方速录；见 ComboPinyin 专题 |
| 地球拼音 | 带调拼音 | 声调韵母可省略→简拼；与【注音】共享词典，**不与朙月拼音相通** |
| 注音 | 大千式键盘，无模式 | 候选用 `Shift+数字`；符号键被占用时按 Shift 取符号 |
| 倉頡 | 形码 | 默认限「通用字符集」，切「通用→增廣」可输入七万余字；☯ = 混元编码器猜的词 |
| 速成 | 仓颡首尾二码 | 支持全码/简码混合 |
| 五笔 86 | 形码，简体优先 | 敲 `z` 转简体拼音反查；另有【五笔·拼音】混合输入 |
| 粤拼 | 香港语言学会粤拼 | **程序自动注音可能标错多音字**，别当标准学 |
| 吳語 | 吴语拉丁式注音 | `\` 后输入普通话反查 |
| emoji | 拼音代码 | 老配置法已过时，用 `github.com/rime/rime-emoji` |

### 反查（`\` 引导键）通则

- 反查需要装上对应的目标方案（仓颡反查需朙月拼音；五笔反查需袖珍简化字拼音）；
- 仓颡码与拼音重码时，**仓颡码优先**；
- 反查码可改：`reverse_lookup/dictionary`（换词典）/ `reverse_lookup/prism`（换拼写方案）/ `reverse_lookup/tips`（提示样式）/ `reverse_lookup/preedit_format`。

## Code Examples

### 一个最小可用方案

```yaml
# my_schema.schema.yaml
schema:
  schema_id: my_schema
  name: 我的方案

engine:
  processors:
    - ascii_composer
    - recognizer
    - key_binder
    - speller
    - punctuator
    - selector
    - navigator
    - express_editor
  segmentors:
    - abc_segmentor
  translators:
    - punct_translator
    - table_translator
  filters:
    - simplifier
    - uniquifier

speller:
  alphabet: zyxwvutsrqponmlkjihgfedcba
  delimiter: " '"
  algebra:
    - derive/^([nl])ue$/$1ve/

translator:
  dictionary: luna_pinyin
  enable_completion: false
```

### 从零做词库

```yaml
# my.dict.yaml
---
name: my
version: '1.0'
sort: original
use_preset_vocabulary: false
...
测试	ce shi
你好	ni hao
```

编译与验证：

```shell
./rime_deployer --compile my_schema.schema.yaml
./rime_console        # 交互查词
echo 'ceshi' | ./rime_console
```

## Anti-patterns

- **把 `enable_sentence` 用在非 `table_translator` 方案上** —— 只对码表类有效。
- **给 `simplifier` 不配 `uniquifier`** —— 同字候选重复。
- **词典里写简拼/异拼编码** —— 码表里没出现过的编码会变成用户词典里的无效数据。
- **导入文本码表时用双引号包含特殊字符** —— Tab 分隔 + UTF-8 **无 BOM**（Vim: `:set fenc=utf8 nobomb ff=unix`）。
- **扩展包与主词典音节表不一致** —— 查得到主词典的音节才算数。
- **改词典前不关输入法** —— 用户词典被独占打开，操作失败。

## Key Takeaways

1. 改行为看 `engine` 四组组件 + `translator` 开关；改候选来源看 `dictionary` / `packs`。
2. 词典正文是 Tab 分隔的码表，不是 YAML。
3. 双拼/语句流/朙月拼音共享词典与用户词典——改一处影响一片。
4. 扩展包省编译时间，但换来兼容性责任。
5. 反查依赖别的方案，缺了目标方案就整条链失效。

# Chapter 6: 用户数据与部署

## Core Idea

改配置只是一半，另一半是**部署**和**用户数据**。用户词典存着你的输入习惯，跨机器迁移靠快照合并而不是文本码表。

## Reference Tables

### 部署怎么做

| 发行版 | 操作 |
|---|---|
| 小狼毫 | 开始菜单 → 小狼毫输入法 → 重新部署；或托盘图标右键「重新部署」 |
| 鼠鬚管 | 系统语言文字菜单 → 「重新部署」 |
| 中州韻 | 状态栏 ⟲ 按钮；或 `touch ~/.config/ibus/rime/; ibus restart` |

部署时编译器把源文件合并成编译结果（`default` + 各方案配置），运行时读的是它。**改完不部署 = 没改。**

### 部署产物与验证

| 产物 | 位置 | 用途 |
|---|---|---|
| 编译结果 | `<用户文件夹>/build/<name>.schema.yaml` | **验证改动的唯一可信证据** |
| 快照 | `<用户文件夹>/build/*.userdb.txt` | 用户词典快照 |
| 日志 | 小狼毫 `%TEMP%\rime.weasel.*`；鼠鬚管 `$TMPDIR/rime.squirrel.*`；ibus `/tmp/rime.ibus.*`；旧版 `<用户文件夹>/rime.log` | 看 `E` / `WARNING` 行 |

## Reference Tables：用户词典管理

### 图形界面与命令行

- **图形**：小狼毫「用户词典管理」（开始菜单/托盘右键）。左侧按词典名列出；**词典与方案可能是一对多**。
- **命令行**：中州韻/鼠鬚管无图形工具，用 librime 编译产物 `bin/rime_dict_manager`：

```shell
cd <用户文件夹>
./rime_dict_manager --list
```

> 执行前**必须关闭正在使用的输入法**——词典文件被独占打开。

### 快照与合并

- Rime 定期把用户词典自动备份为 `*.userdb.txt`；
- 合并只需选定 `.userdb.txt`（快照里记着所属词典名）；
- **词频取二者较大值**，其他参数按合理算法叠加；
- 迁移数据**优先用快照合并**，文本码表信息不全。

### 导出/导入文本码表

导出格式与静态码表相同：**Tab 分隔三列 = 文字、编码、频次**；编码是码表定义的完全形式，多音节间空格分隔。

可反向导入用户词典，但**推荐导入固态词典**（`*.dict.yaml`）。要完全替换 `luna_pinyin`：把新词典命名为 `luna_pinyin.dict.yaml` 放进用户文件夹，重新部署。

若坚持导入已有用户词典，四项检查：

1. 编码 **UTF-8 无 BOM**（Vim：`:set fenc=utf8 nobomb ff=unix`）；
2. **Tab 分隔**，至少「文字、编码」两列，频次列可选；
3. 字形（繁/简）与源码表一致——用 OpenCC 转换；
4. 编码形式是码表里的标准形式——**简拼/异拼/拼写错误会成为用户词典里的无效数据**（检索不到）。

### 自定义短语

文本文件即可，放用户文件夹的 `custom_phrase.txt`，重新部署生效。朙月拼音已内置相关设置；自定义方案需自行加两处代码（rime-luna-pinyin 的 `luna_pinyin.schema.yaml` L49 / L72）。

## Code Examples

### 编译与调试三件套

```shell
# 编译单个方案
./rime_deployer --compile luna_pinyin.schema.yaml
# 给已部署方案打补靪
./rime_patch luna_pinyin 'translator/packs' '[sample_pack]'
# 控制台查词
echo 'cubizhiyu' | ./rime_console
```

### 同步用户数据

在 `installation.yaml` 里指定同步目录：

```yaml
sync_dir: /path/to/your/sync/folder
```

> **「同步」指用户数据同步，不是配置同步**。配置要在每端分别维护，用 git 管。

## Anti-patterns

- **不关输入法就跑 `rime_dict_manager`** —— 词典文件被独占，操作失败。
- **用文本码表迁移用户数据** —— 信息不全，词频与参数丢。
- **码表文件带 BOM** —— Rime 要求 UTF-8 无 BOM。
- **把「同步」理解成配置同步** —— 配置在每端各改各的。
- **在共享文件夹里找用户词典** —— 用户词典在用户文件夹。
- **把 `build/` 里的文件当源文件编辑** —— 下次部署会覆盖掉。

## Key Takeaways

1. 部署是改与生效之间唯一的开关；验证看 `build/`，不是看源文件。
2. 用户词典是独占资源，任何词典工具前先退出输入法。
3. 迁移用快照，不用文本码表。
4. 文本码表导入的四个检查点：编码、Tab 分隔、字形、编码形式。
5. 自定义短语是「不想建词典」时的轻量替代。

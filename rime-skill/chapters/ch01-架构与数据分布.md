# Chapter 1: 架构与数据分布

## Core Idea

Rime = **跨平台输入引擎（librime）+ 数据（方案/词典）+ 平台前端（小狼毫/鼠鬚管/ibus）**。你改的几乎永远是中间那层「数据」；引擎改不了，前端只管显示。

## Key Concepts

| 术语 | 精确含义 |
|---|---|
| **engine 引擎** | 把「按键 → 编码 → 查词典 → 候选 → 上屏」写成程序的部分。不含码表数据、不含 OS 交互、不含界面 |
| **schema 输入方案** | 跨输入法通用框架里「因方案而异」的部分 = 配置信息 + 词典。改行为基本都改这里 |
| **词典 / 韵书** | 编码 ↔ 候选文字的映射表（码表）。`*.dict.yaml` 源文件，编译成 `*.table.bin` + `*.prism.bin` |
| **拼寫運算** | 在输入码与词典编码之间建映射的机制。模糊音/简拼/双拼全靠它 |
| **共享文件夹** | 发行版自带的方案、词典、默认配置源文件、预编译 `build/` 缓存。**只读** |
| **用户文件夹** | 你的下载/自定义文件 + 运行时数据（用户词典、安装信息、选项状态） + 部署产物 |
| **部署 Deploy** | 把源文件编译成运行时读的配置。**不部署 = 没改** |

**查找优先级：用户文件夹 → 共享文件夹。**

## Reference Tables

### 文件夹位置（必须用绝对路径）

| 发行版 | 用户文件夹 | 共享文件夹 |
|---|---|---|
| 小狼毫（Windows） | `%APPDATA%\Rime` | `<安装目录>\data` |
| 鼠鬚管（macOS） | `~/Library/Rime` | `/Library/Input Methods/Squirrel.app/Contents/SharedSupport` |
| ibus-rime | `~/.config/ibus/rime` | `/usr/share/rime-data` |
| fcitx-rime | `~/.config/fcitx/rime` | `/usr/share/rime-data` |
| fcitx5-rime | `~/.local/share/fcitx5/rime/` | `/usr/share/rime-data` |

### 用户文件夹内容

| 类别 | 文件 |
|---|---|
| 你写的 | `<方案>.schema.yaml`、`<韵书>.dict.yaml`、`<词典>.txt`、`<配置>.custom.yaml`、`opencc/*` |
| 运行时产生 | `<语言代号>.userdb/`（用户词典）、`installation.yaml`（安装/升级信息）、`user.yaml`（当前方案与开关状态） |
| 部署生成 | `build/`（编译结果，**验证时看这里**） |

## Worked Example

一次定制的完整链路（以「改小狼毫候选数」为例）：

```
1. 定位        要改的是全局菜单设置 → 落在 default.custom.yaml（不是 luna_pinyin.custom.yaml）
2. 写补靪      patch: { "menu/page_size": 9 }
3. 放对位置    %APPDATA%\Rime\default.custom.yaml
4. 部署        开始菜单 → 小狼毫输入法 → 重新部署
5. 验证        打开 %APPDATA%\Rime\build\default.yaml 找 menu/page_size 是否为 9
6. 现场复现    敲几个字，看每页是不是 9 个候选
```

关键在第 5 步：`build/` 里是**合并后的最终配置**，源文件对不对它说了算。

## Anti-patterns

- **把「引擎」当「方案」改** —— 想改按键行为，改的是方案里的 `key_binder` / `editor` 段，不是引擎。
- **在共享文件夹里改文件** —— 升级即失，且可能被只读保护。
- **改了源文件不部署就验收** —— 运行时读 `build/`，你的改动根本还没进运行时。
- **用相对路径指定用户文件夹** —— librime 不支持，行为未定义。

## Key Takeaways

1. 行为差异来自「方案」，数据差异来自「词典」，显示差异来自「前端」。
2. 共享文件夹只读、用户文件夹可写；查找时用户优先。
3. `build/` 是唯一可信的「改完是什么样」的证据。
4. 部署是改与生效之间的**唯一开关**。

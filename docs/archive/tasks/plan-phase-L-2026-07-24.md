## 1. 调整 1：取消"用户词典编辑"模块

### 1.1 这功能是什么,为什么要取消

"用户词典编辑"是一个独立的窗口,让用户能手动加词、改词、删词、加权重。这模块之前为了配合输入法智能学习做了不少。

但 user 决定**不做了**,因为:
- 装机后从用户反馈看,常用 80% 场景是常用短语,用户词典用得很少
- 这模块维护成本高 (L97 stale binary bug 多次踩这个坑)
- 输入法本身会自动学用户输入,不需要手动编辑

### 1.2 要清理的内容

| 清理项 | 说明 |
|---|---|
| 浮动设置栏的"用户词典"按钮 | 现在浮动设置栏有 7 个按钮,其中一个是用户词典,要去掉 |
| 设置栏(快捷设置栏)的"用户词典编辑"按钮 | 独立的快捷键设置窗口里也有这个按钮,要去掉 |
| 快捷键 Ctrl+Shift+U | 现在按这个组合键会打开用户词典窗口,要把这个快捷键移除 |
| 后台代码 (UserDictionary 相关) | 删掉或注释掉所有跟"用户词典编辑窗口"有关的代码 |
| 编译选项 | 把项目里相关编译条目去掉,避免浪费编译时间 |

### 1.3 调整后的样子

用户装机后看到的:
- 浮动设置栏的按钮变成 6 个(常用短语 / 设置 / 文件夹 / 中英文切换 / 等等 — 不再有"用户词典")
- 设置栏(快捷键设置)里**没有**"打开用户词典"这个选项
- 按 Ctrl+Shift+U 不再有任何反应(快捷键回收,以后有新功能可以再用)

### 1.4 时间预估

- 代码清理 + 测试更新: **2-3 小时**
- 重新打包安装程序 + 装机验证: **1 小时**
- **小计: 约 3-4 小时**

## 2. 调整 2：所有输入法方案都支持中文标点

### 2.1 现状

火流猩内置了多个输入法方案:拼音(全拼)、双拼(微软/搜狗/小鹤/...)、注音。每个方案都有自己的"中文标点"设置,就是按键盘上的英文符号键时,自动转成对应的中文符号:

| 键盘按键 | 中文模式输出 | 英文模式输出 |
|---|---|---|
| `,` (逗号) | `，` | `,` |
| `.` (句号) | `。` | `.` |
| `?` (问号) | `？` | `?` |
| `(` | `（` | `(` |
| `"` | `"` `"` | `"` |

**问题**: 有些方案(尤其是双拼的几个变体)这个映射**没配全**,导致用户切到那些方案时,按 `,` 还是出英文逗号,不是中文逗号。

### 2.2 目标

不论用拼音、双拼还是注音,只要**切到中文输入状态**,按键盘上的符号键就**一定**输出对应的中文符号。

切换回英文状态时,正常出英文符号(跟现在一致)。

### 2.3 实施范围

- 火流猩内置的所有方案(目前大概 8-10 个 schema 文件)
- 用户的自定义方案**不强制改**(让用户自己决定)

### 2.4 装机后怎么验证

- 装好后,挨个切方案试一次:
  - 拼音 → 中文模式 → 按 `,` → 应该出"，"(中文逗号)
  - 微软双拼 → 中文模式 → 按 `,` → 应该出"，"
  - 小鹤双拼 → 中文模式 → 按 `,` → 应该出"，"
  - 注音 → 中文模式 → 按 `,` → 应该出"，"
  - 英文模式 → 按 `,` → 都出英文逗号 ","(没变)

### 2.5 时间预估

- 检查所有方案配置 + 补齐缺失的: **1-2 小时**
- 写测试用例 + 跑测试: **1 小时**
- **小计: 约 2-3 小时**

## 3. 调整 3：切换到火流猩时浮动设置栏自动弹出

### 3.1 这是什么

"浮动设置栏"就是右下角那个 6 按钮的小面板,用户可以快速切方案、开关中英文、打开常用短语等等。

之前的 v0.19.0.32 版本做过"打开输入法就自动弹浮动设置栏",但**被撤回了**(spec 074),原因是:
- 用户开机后输入法一直在后台跑,每次开电脑就弹一次,太烦了
- 误触率高,影响打字

### 3.2 新版本要做的

触发条件**改成**:**用户主动切换到火流猩输入法**时才弹。也就是:
- Win+Space 选到火流猩 → 浮动设置栏弹一下
- 点语言栏切换到火流猩 → 浮动设置栏弹一下
- 开机输入法已在后台跑 → **不弹**
- 火流猩里切方案(拼音 ↔ 双拼) → **不弹**(只是换输入方式,不算"切换到火流猩")

弹出来之后:
- 按 Alt+, → 隐藏
- 再按 Alt+, → 重新显示
- 用户也可以直接点浮动设置栏上的 X 关闭

### 3.3 跟之前被撤回的版本有什么不同

| 维度 | 之前(被撤回) | 现在(新做) |
|---|---|---|
| 触发时机 | 服务启动就弹 | **用户切到火流猩才弹** |
| 误触率 | 高(每次开机都弹) | 低(用户主动操作才弹) |
| 关掉方式 | 自动隐藏(1.5秒) | 按 Alt+, 主动关 |
| 用户感知 | "烦,关掉" | "哦,这是欢迎提示" |

### 3.4 实施要点

- 检测"用户切换输入法"事件(Windows API 有专门的通知)
- 切换到火流猩时,调浮动设置栏的"显示"接口
- 不能影响打字:浮动设置栏必须"不抢焦点",否则用户切输入法之后打第一个字会失败

### 3.5 装机后怎么验证

- 装机后开机 → 不弹浮动设置栏 ✓
- Win+Space 切到别的输入法(比如英文) → 不弹 ✓
- Win+Space 切回火流猩 → **浮动设置栏自动弹** ✓
- 按 Alt+, → 浮动设置栏隐藏 ✓
- 再按 Alt+, → 浮动设置栏显示 ✓
- 弹出来后,在记事本里打字 → 不卡、不丢字 ✓

### 3.6 时间预估

- 写"切换输入法监听"代码: **2 小时**
- 调试误触发(避免切方案也弹): **1 小时**
- 测试 + 真机验证: **1-2 小时**
- **小计: 约 4-5 小时**

## 5. 装机验证清单(三个 ship 都要跑)

不管发哪个版本,装机后必跑:

1. **浮动设置栏 Alt+, 切换**: 显示 → 按 Alt+, → 隐藏 → 再按 Alt+, → 显示
2. **切换输入法弹浮动设置栏**: Win+Space 切到火流猩 → 弹;切到别的 → 不弹
3. **设置栏没有用户词典按钮**: 打开设置栏(快捷键设置) → 找不到"用户词典"按钮
4. **所有方案中文标点**: 切到火流猩 → 试拼音 → 试双拼 → 试注音 → 按 `,` 都出中文逗号
5. **不打字冲突**: 浮动设置栏弹出时,在记事本里能正常打字(不丢字、不卡)

## 1. 选定理由（用户视角）

方向 A 是三稿中唯一**信息结构**与真实使用场景对齐的：把「当前输入态（中/英、全/半角）」从
「藏在图标里」升级为**面板里最显眼的状态读数**，动作键（切换输入法 / 用户短语）退为两侧安静的图标。
这直接命中用户此前反馈的痛点：图标看不懂、状态不明确。

方向 B（顶级定制）视觉更精致但状态仍藏在图标里；方向 C（复古未来）风格强烈但与「工具面板」的
功能性、克制感相冲突，且与品牌识别（暖白 + 品牌橙）脱节。

## 2. 借什么 / 不借什么（硬约束）

| 类别 | 内容 |
|---|---|
| **借（结构语法）** | 半透明层级 · 1px 发丝描边 · 分层软投影 · 分组分隔线 · 光学均衡（轨道内元素居中于轨道而非整面板） |
| **不借（配色/材质）** | Fluent 蓝、Mica、Acrylic 毛玻璃、背景采样、reveal 呼吸光 |
| **品牌色用法** | 品牌橙 `#FF5F31` **只**用于「中文侧状态」与「hover 键帽」；不做大面积品牌色 |

### 3.2 几何分区

|---|---|---|

### 3.3 元素细节

- **视觉位 0 切换输入法**：双向箭头 `M5 11H23 / M19 8L23 11L19 14 / M25 19H7 / M11 16L7 19L11 22`，stroke `#6F6A62`，width 2。
- **视觉位 3 用户短语**：对话气泡 `rect(5,5,20,15,rx6)` + 尾巴 `M10 20L8 25L13 20` + 两行文本线，stroke `#6F6A62`，width 2。
- **视觉位 1 中/英**：**文字读数**（不再是图标）。中文态填 `#FF5F31`，英文态填 `#241F1A`，`font-size 16 / weight 700`，按**墨迹盒**居中于轨道左半。
- **视觉位 2 全/半角**：中文态 = 空心环 `circle(21.5,7.5,r=5.5)` stroke `#FF5F31` w1 + 中文逗号；英文态 = 实心点 `circle(20.5,7.5,r=3.5)` fill `#241F1A` + 英文逗号。
- **hover 键帽**：`rect(93,2,28,28,rx10)` fill `#FF5F31` @0.10 + 1px 描边 `#FF5F31` @0.50；**只改键帽，不动轨道**。

### 3.4 GDI 退化规则（不可协商）

交付形态为 **Win32 GDI 自绘**（32-bit BGRA DIB + `UpdateLayeredWindow`）。
以下设计手法**一律退化**，不得引入 GDI+ / D2D / blur / backdrop-filter：

| 设计手法 | GDI 退化实现 |
|---|---|
| 毛玻璃 / 背景采样 | 半透明**纯色** `#FAF7F2` @0.72 |
| Fluent reveal 呼吸光（32px 光晕） | hover 时**键帽轮廓浮出**（描边 + 淡底） |
| 逗号为真实字形 | 按目标**墨迹盒**反推字号：中文逗号 SimSun 48 / 英文逗号 Times New Roman 52 |
| 「中/英」按视觉居中 | 按 **墨迹盒**（`GetGlyphOutlineW` GGO_METRICS）居中，不用 `DT_VCENTER` 兜底 |
| 分层投影 | 3 层圆角矩形叠加，直接写 DIB 的 alpha 通道 |
| 轨道 / 键帽分层 α | 直接写 DIB 逐像素 alpha，不做整体 alpha 缩放 |

### 3.5 与当前生产实现的差异清单（实现时逐条对照）

1. 面板底色：浅蓝渐变 `#C8E1FA→#9BC3F0` ⇒ 改为 `#FAF7F2` @0.72 纯色。
2. 面板外描边：新增 `#4A453D` @0.28 1px 发丝。
3. 顶部高光发丝：新增 `#FFFFFF` @0.55。
4. 分层软投影：新增 3 层 `#1B1814`（y 偏移 1.5 / 3.5 / 6，α .05/.04/.03）。
5. 品牌区分隔发丝：新增 x=31.5 竖线 `#4A453D` @0.18。
6. 状态轨道：新增圆角胶囊底 `#4A443A` @0.07 + 内描边 `#FFFFFF` @0.22。
7. **视觉位 1 由「图标」改为「中/英」文字读数**（结构改动最大的一项）。
8. 视觉位 2：环 stroke / 点 fill 改用方向 A 色值。
9. 动作图标墨色：`RGB(130,130,140)` ⇒ `#6F6A62`。
10. hover 键帽：新增描边浮出。

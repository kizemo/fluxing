快捷设置栏 v2 · 契约式

技能：$api-and-interface-design 核心思路：每个按钮是一份"调用契约"——输入、状态来源、点击事件、副作用全部写清。 对应规格：宽 ≈ 300px；按钮 7 个，每个 24px 高；总高 36px。

视觉预览（点哪个都有反应）

按钮契约清单（一行一个）

按钮显示状态点击行为（契约）前置条件
方案 始终可用 弹出方案子菜单（与 F4 行为一致）；选中后切换方案 + 收起设置栏 —
字典 始终可用 打开"用户字典编辑"窗口（spec 007 §1.2.4）；不收起设置栏 —
短语 始终可用 打开"常用短语编辑"窗口（spec 009）；不收起设置栏 —
中/英 高亮 = 当前中文模式 切换 ascii_mode，状态同步到托盘图标；Shift 同样触发 —
全/半角 高亮 = 当前全角 切换 full_shape；Ctrl + . 同样触发 —
符号 始终可用 弹出软键盘面板（特殊符号 + 表情），点选上屏后收起 —
登录 预留位，未登录：显示 登录；已登录：显示用户名首字 + 悬停提示"已登录 / 退出登录" 本期：点击 → 弹"云同步功能即将上线"toast；spec 010 上线后接注册/登录流程 云同步 spec 010 上线

契约版本

按钮契约 v1.0，与设置栏窗口类 FluxingQuickPanel_v1 同生命周期；后续若加按钮，按 v1.1 递增，并在 include/resource.h 新增 ID。

交互细节

  • 每个按钮 24px 高，按钮间无空白用 2px 间距，分组间用 1px 浅分割线。
  • 激活态：浅蓝底 + 蓝字 + 加粗；非激活态：透明底，悬停时变 #f0f0f3。
  • 工具提示 title 含快捷键；预留按钮置灰且不响应。
  • 整体高度 ≤ 36px；窗口默认 90% 透明，鼠标悬停 0% 透明，200ms 过渡（spec 049）。

验收

  • 7 个按钮全部能看见、能点击；视觉一行不超 300px。
  • "中/英""全/半角"激活态正确反映当前状态。
  • "方案"按钮与 F4 都能弹出方案菜单。
  • "登录"按钮置灰，悬停提示"功能即将上线"。

技能适配说明

本稿借 $api-and-interface-design 的"契约优先"思想：每个按钮 = 一份调用契约（输入 / 状态 / 输出 / 前置）。文档化每个按钮的副作用，避免按钮功能"含混"。不足：未规定视觉态，依赖实现者自由发挥。

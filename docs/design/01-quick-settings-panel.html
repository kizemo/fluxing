中/英中文

全/半角全角
当前方案：朙月拼音
默认 90% 透明；鼠标移上去变清晰；3 秒不操作自动收起。

何时出现 / 何时消失

  • 切到火流猩输入法 → 自动出现在屏幕右下角（距屏幕右 32px、距底部 48px）
  • 切到其它输入法 → 自动收起，不抢屏幕
  • 未激活火流猩时按 Alt + , → 不响应（避免误触）
  • 激活火流猩时按 Alt + , → 在 显示 / 隐藏 之间切换
  • 鼠标移开 → 3 秒后自动收起
  • 点右上角 × 或按 Esc → 立即收起

控件清单（每个控件能做什么）

标题 "Fluxing"
说明这是火流猩的设置栏，不可点。
关闭 ×
立即收起本面板。
中/英（开关）
点一下 → 输入法在"中文模式 / 英文模式"之间切换；当前是哪个，文字会高亮成蓝色。
简/繁（开关）
点一下 → 在"简体输出 / 繁体输出"之间切换。
全/半角（开关）
点一下 → 在"全角字符 / 半角字符"之间切换（影响中文标点 / 英文标点）。
当前方案 + 切换
显示你正在用的输入方案（例如"朙月拼音"）；点"切换"→ 弹出方案列表，选一个就换成它。本期按钮可以先不连后端，留空响应。
用户文件夹
打开系统文件管理器，定位到你的个人配置目录（你的用户词典、自定义短语都在这里）。
程序文件夹
打开系统文件管理器，定位到火流猩的安装目录（默认配置文件、皮肤都在这里）。
部署
让火流猩立刻把改动同步到引擎，相当于重启引擎但更轻量。
退出
关闭火流猩，停止打字上屏。

视觉规范（一眼看过去是什么样）

风格
macOS 浅色卡片，圆角 14px，轻投影；不抢戏，跟系统主题协调。
位置
屏幕右下角，距屏幕右 32px、距底部 48px（贴任务栏上方 8px）。
尺寸
宽 320px × 高自适应（约 230px）。
透明度
默认 90% 透明（看得到但模糊）；鼠标移上去 → 0% 透明（完全清晰）；切换有 200ms 平滑过渡。
暗色主题
跟随 Windows 系统主题（浅 / 深），过渡 200ms；用户不改也基本可用。
字体
系统默认中文字体；标题 14px、正文 13px、说明 11px。

交互细节（让用户用得顺手）

  • 所有按钮在键盘上按 Tab 可逐个聚焦，回车 = 点击。
  • 鼠标悬停时按钮颜色加深 5%，给出"可点"的反馈。
  • 透明度切换有 200ms 过渡，不是突然变。
  • 关闭按钮（X）和"退出"是两个不同概念：X 只收面板，退出是真的关掉输入法。

本期先不实现的部分（按钮留空）

  • "切换"方案 → 弹出列表选方案（本期先不连，按钮可点但无反应或弹"即将上线"）
  • "用户文件夹 / 程序文件夹 / 部署 / 退出" → 先做到按钮显示正常、文案正常、悬停效果正常；点击功能后面单独做。

验收（怎么算"做好了"）

  • 切到火流猩输入法 → 设置栏出现在右下角，时间 < 200ms。
  • 切到其它输入法 → 设置栏立刻消失。
  • 按 Alt + ,（激活态） → 在显示 / 隐藏 之间切换。
  • 按 Alt + ,（未激活态） → 没反应。
  • 鼠标移上去 → 1 秒内变清晰；离开 → 1 秒内变模糊（90% 透明）。
  • 鼠标离开后 3 秒 → 面板自动消失。
  • 点 X 或按 Esc → 面板立刻消失。
  • 面板出现期间，原有打字功能不受影响。
  • 右键托盘 → 菜单中"快速面板 (K)"仍能手动唤出。

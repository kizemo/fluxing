快捷设置栏 v3 · 设计系统式

技能：$frontend-ui-engineering 核心思路：每个按钮复用 IconButton 组件；用设计令牌驱动样式；键盘可达；三态严格；可达性优先。 规格：宽 288px；按钮 7 个，32×28px；总高 36px。

视觉预览（鼠标 / 键盘都能用）

设计令牌（design tokens）

spacing--space-1=4px, --space-2=8px, --space-3=12px
radius--radius=6px（统一圆角，不许随意改）
color text  muted  hover  pressed  accent-soft  accent
typography系统字体栈；正文 13px / 标题 18px
motion状态切换 200ms ease-out；透明度（窗口层）90% → 0%，200ms

IconButton 组件规范

size32×28px；图标 16×16px 内嵌 SVG
state · default背景 transparent，文字 --text
state · hover背景 --hover (#f0f0f3)
state · pressed背景 --pressed (#e6e6ea)
state · focused (键盘)2px outline --focus (rgba 蓝)
state · aria-pressed=true背景 --accent-soft，文字 --accent
state · disabledopacity .4，cursor not-allowed，不响应 hover
a11y必须 aria-label；toggle 用 aria-pressed；icon 用内嵌 SVG 不当装饰
tooltip用原生 title，文案：动作 + 快捷键（如"中 / 英 (Shift)"）

键盘可达（Tab 顺序即按钮顺序）

1.方案 → 2.字典 → 3.短语 → 4.中英 → 5.全半角 → 6.符号 → 7.登录（disabled，焦点跳过）

回车 = 点击；Esc = 关闭设置栏；Tab 在按钮间切换聚焦。

为什么这样设计

  • 图标按钮省空间（v2 占 300×36，本版 288×36）；不依赖 emoji 字体，避免 Windows 上字体替换导致的渲染差异。
  • SVG 内嵌矢量，HiDPI 不糊；颜色用 currentColor 自动跟随主题。
  • 所有按钮用同一个 .ib 类，新增按钮无需写新样式。
  • 设计令牌集中在 :root，暗色主题切 data-theme="dark" 即可。
  • 三个 toggle（中英、全半角、登录态）一律用 aria-pressed，屏幕阅读器能听懂。

验收

  • 设置栏 288×36px，7 个按钮均匀分布，无文本遮挡。
  • 键盘 Tab 7 次可依次聚焦，Esc 关窗口；登录按钮聚焦跳过。
  • 中英 / 全半角 toggle 用 aria-pressed 反映状态。
  • 悬停整行 200ms 内变 0% 透明；离开回 90% 透明。
  • 暗色主题下 data-theme="dark" 自动切换配色（spec 033 集成）。

技能适配说明

本稿借 $frontend-ui-engineering 的设计系统思路：tokens → 组件 → 状态 → 可达性。不足：每个按钮的"调用契约"（状态来源 / 事件 / 副作用）写在 v2 表里更清楚，正式实现时两表合并。

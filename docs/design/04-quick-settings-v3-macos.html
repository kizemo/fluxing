全半角图标设计

  • 全角（中文标点）：左下粗逗号（大弧度弯钩）+ 右下大句号（2.4px 半径实心圆），呼应搜狗/微软中文标点风格。
  • 半角（英文标点）：左下细逗号（小弧度弯钩）+ 右下小句号（0.9px 半径实心圆），比例约为全角的 1/2。
  • 切换实现：CSS 选择器 .ib[aria-pressed="false"] .ico.fullwidth { display: none }，无需 JS。

品牌图标设计

  • 26×26 圆角方块（圆角 8px），蓝→紫渐变背景。
  • 中央 18×18 <img> 引用 fluxing-logo.png。
  • filter:brightness(0) invert(1) 把红褐剪影转为白色（叠在渐变上）。
  • 内描边 0.5px 白色 18% 透明，模拟 macOS 图标高光。

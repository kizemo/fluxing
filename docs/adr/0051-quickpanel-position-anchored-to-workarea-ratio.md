# ADR 0051 — 快捷面板位置按「相对工作区的比例」锚定（落盘升 v2）

- 状态: 已采纳 (2026-11-10)
- 影响范围: `include/FluxingPanelPosition.h`（新建）、`WeaselServer/QuickPanelDialog.{h,cpp}`、`test/TestQuickPanelDialog`
- 决策类型: 架构决策（位置语义 + 落盘格式 + 重锚触发点）+ 缺陷根因结论
- 关联: 交接 `docs/archive/handoffs/handoff-2026-11-10-batch-v-panel-anchor-and-theme.md`；用户真机反馈「键槽图标相对大小已不变，但分辨率增大后设置栏位置会向左上偏移」
- 前序: ADR 0035（位置持久化到 `quickpanel.position`）、ADR 0049/0050（统一缩放系数、4 槽化）

## Context

### 用户真机现象

批次 U（ADR 0050）收尾后用户复验：**键槽图标的相对大小已不再随分辨率乱变**，
但**面板相对屏幕的位置**在分辨率变化时会大幅偏移——分辨率变大后，设置栏向左上漂。

### 根因不是 DPI，也不是钳制算法

1. **不是缩放系数**：ADR 0049 已把键帽 / 槽位 / 窗口 / 图标几何统一到同一个系数，
   且用户确认「图标相对大小已对」⇒ 几何侧已闭环。
2. **不是钳制**：`ClampToVisibleArea` 只在面板**出屏**时兜底，
   而「分辨率变大后坐标不变」时面板**仍在屏内**（只是相对位置偏了）⇒ 钳制根本不会被触发。
3. **是位置语义**：ADR 0035 把位置按**绝对物理像素**落盘。
   分辨率变大 ⇒ 工作区变大而坐标不变 ⇒ 面板相对屏幕必然向左上漂。

⇒ 病灶在「位置用绝对坐标表达」这件事本身，不是某个算式的 bug。

## Decision

1. **位置语义改为比例锚点**：落盘 `(x, y, fx, fy)`，其中 `fx/fy ∈ [0,1]` 表示
   「面板左上角相对**所在工作区可摆放空间**的比例」。
   分母 = 工作区尺寸 − 面板尺寸（面板贴边时 fx/fy 恰为 0 或 1，量化无歧义）。
2. **落盘升 v2，但前两行与 v1 完全一致**（`x` / `y`），锚点另起两行。
   ⇒ 旧解析器照样能读 v2 文件；**缺任一锚点字段 ⇒ 整份文件按 v1 处理**
   （不半途解析，避免半截字段产生错误锚点）。
3. **不需要迁移脚本**：用户下一次拖动面板即写出 v2；
   在此之前旧 v1 文件继续按「绝对坐标」解释（行为与今天一致）。
4. **重锚触发点四处**（缺一不可）：
   `Show()`（每次显示）、`WM_DPICHANGED`（缩放变了）、`WM_DISPLAYCHANGE`（分辨率变了）、
   `WM_SETTINGCHANGE` 且 `SPI_SETWORKAREA`（工作区变了，如任务栏/副屏状态）。
   `WM_DISPLAYCHANGE` **无条件重锚**；`WM_SETTINGCHANGE` 只在 `SPI_SETWORKAREA` 时重锚。
5. **认显示器**：先按**原点相同**判定（分辨率变了原点通常不变 ⇒ 仍认得同一块屏），
   再按**交集最大**，最后按**中心距离**兜底。
   原屏已从列表中消失 ⇒ 落到**最近的那块屏**，**不返回 nullptr**（面板不许凭空消失）。
6. **`Show()` 三级优先级**：锚点（v2）→ 旧绝对位置（v1）→ 右下角默认。
7. **写盘后回读自证**：`WritePositionRecordFile` 写完立即读回校验，
   避免「写成功但内容不对」被当成成功。
8. **`SavePositionAt()`（写 v1）作废锚点缓存**：旧接口仍可用，但它写出的是绝对坐标，
   与锚点语义互斥 ⇒ 调用后必须让运行期缓存失效，否则下次 `Show()` 仍按旧锚点重映射。

## Consequences

- 分辨率变化后面板**相对屏幕的位置不漂**（按比例重映射到新工作区）。
- 旧的「绝对坐标」语义**只保留给 v1 文件**，不再用于新写入。
- 单一真相源在 `include/FluxingPanelPosition.h`（锚点纯函数 + v1/v2 落盘 + 读写），
  生产代码与单测读**同一份**（constitution R7）；单测 T40 组 26 条断言覆盖
  锚点生成 / 往返不变量 / 显示器匹配 / v1-v2 兼容 / 写盘回读。
- **仍需用户人工复验**：快捷面板是 IME 激活瞬间才存在的自绘顶层窗，
  跨进程自动化抓不到（见批次 U 交接 §7.8）；自动化只能给到单测级证据。
